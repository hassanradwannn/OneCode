# OneCode — set up on another Windows PC

## Version 0.4.4

0.4.4 is an application hotfix for a compatible 0.4.3 installation. New users and users on 0.4.2 or earlier first run the [0.4.3 base installer](https://github.com/hassanradwannn/OneCode/releases/download/v0.4.3/OneCode-Setup-x64.exe), then open **Settings → General → Check for updates → Install when done**. Do not run or extract the hotfix ZIP into the installation manually. The verified internal updater applies it after work finishes and restarts the app.

After the update, **What's new** shows the installed release's highlights once. It waits for any other dialog to close. Reopen it under **Settings → General → What's new → View changes**, then choose **Full release notes** for that version's GitHub release. **Got it**, Escape or the backdrop closes the pane. A same-version restart and a fresh installation do not show it automatically.

## Connection fixes included from 0.4.3

Public checks now allow slower valid HTTPS/MCP replies and distinguish a timeout from a TLS failure. Install 0.4.3 normally through Settings → General → Check for updates → Install when done. This enables smaller compatible application hotfixes in the same internal updater; they activate after work finishes and OneCode restarts. See [hotfix updates](HOTFIX-UPDATES.md).

If OneCode works locally but shows **Public TLS connection failed**, open **Settings → Connection → Repair public connection**. Windows may ask for administrator approval to restart Tailscale. This briefly interrupts Tailscale connections. OneCode retains the existing routes and URLs and verifies public DNS, HTTPS and MCP again before showing Connected. Cancelled or failed repairs are not repeated automatically. Wait for running tools to finish before using this action.

The 0.4.1 DNS negotiation fix remains included: either Cloudflare or Google can independently verify public access. Saved connector URLs and Remote bookmarks are preserved. Account consent, captive portals and blocked network access still require the corresponding native action.

OneCode Core provides permitted local tools, installed integrations and managed skills through one connection per provider. Existing chats can discover newly added integrations without starting another chat. Remote preserves project placement and each chat's provider. Recurring checks save the requested interval and message, then send in that same chat until cancelled; keep the PC awake, OneCode running and the provider signed in.

The model can present completed local photos and videos inline on desktop and Remote. It uses Core `artifact`: begin with `kind:"image"` or `kind:"video"`, then call the corresponding action with the returned `presentation_id` and an approved local file path. Images support PNG/JPEG/WebP; videos support MP4/WebM up to 128 MiB with playback controls. Original files remain in place. Browser recovery, native steering and model refresh retain each chat's exact provider and delivery receipt.

Windows setup detects browsers in custom folders and on other drives, saves the selected browser before sign-in opens, and offers **Locate browser executable…** for portable installs.

Remote mobile settings wrap their category buttons and controls to the screen and scroll vertically. In **Settings → Remote**, copy the private link once and bookmark the complete address, including its fragment. That installation retains its encrypted key and private port across restarts, updates and turning Remote off and on. Open or reload the bookmark to renew a browser connection after a restart or session expiry. Turning Remote off closes access immediately without changing the bookmark. The host PC, OneCode and Tailscale must be running; changing the Tailscale device identity or hostname requires a new link. If another program replaces the saved route, OneCode reports the conflict rather than silently changing the address. Choose **Refresh link** in **Settings → Remote** to select a free private port without modifying the conflicting route, then copy the replacement link and update your bookmark.

Shared OneCode controls use **provider** or **agent** wording. Choose the actual service in **AI provider**; browser destinations, account checks and tool routing remain provider-specific. Existing chats keep their original provider.

Use **Settings → General → Check for updates**, then **Install when done**. The app waits for active work before restarting. The matching Companion reloads when its chats are idle. If an older 0.2.9 install reports a missing `resources/app-update.yml`, install the current release manually once.

Interactive web previews default to **Fit · Responsive**, using the available preview size without shrinking a desktop layout. The **Preview viewport** selector also offers **16:9 · Desktop** (1600×900) and **9:16 · Phone** (450×800) simulations. Expanding keeps the same interactive state. Preview storage is document-local when native storage is inaccessible; generated pages must work without persistent storage.

## Firefox

OneCode 0.4.2 for Windows does not include a signed Firefox Companion package. Use Chrome, Edge or Brave with the bundled OneCode Companion. Firefox executable detection remains available, but detection alone does not establish a provider connection. Setup links to this status instead of downloading a different project's extension.

For multiple computers, set **Name for this computer** before adding each device's MCP URL. Both MCP identity fields publish the configured full name. OneCode accepts a unique native title-cased/dash-to-space presentation only after selecting and verifying its real menu token. Different-device and ambiguous duplicate names are refused. Existing native connectors are not renamed by this update.

The Companion dismisses the recognized English response-comparison question through its separate **Skip / I prefer this option** footer. The question and both numbered options must be present. A thinking **Skip**, isolated button, hidden control or unknown layout is left untouched.

Share **OneCode-Setup-x64.exe**, its distributor-provided SHA256, and this guide. The installer includes the desktop application, companion extension, Cloudflare/search programs, native libraries, and a private Node.js/npm runtime for npm MCP plugins. Your friend does not need this source checkout, your folders, a separate Node installation, or your Google account. The recommended Tailscale connection uses a separate Tailscale installation and the recipient's own account; neither is bundled.

## Requirements and limits

- This installer is for **Windows x64 (Intel/AMD), Windows 10 or later**. Use a Windows version still supported by Microsoft. This is not a 32-bit or ARM64 Windows package. Windows 7/8/8.1 are unsupported. Organization policies and device security software can impose additional restrictions.
- Install a current Brave, Chrome or Edge browser. Sign into your own Gemini or ChatGPT account there. The account must expose custom MCP apps; availability and quotas are controlled by the selected provider. Organization policies may block custom apps, unpacked extensions or debugging permission.
- Internet access is needed for the selected provider and the HTTPS tunnel. Installing external plugins may download their packages. Python plugins can download a verified private uv/Python runtime; their host applications and service accounts remain separate prerequisites.
- This app is not code-signed unless the distributor explicitly supplies a signed build. Check the installer hash with the distributor. Do not disable antivirus or Windows security to install it; report a block to the distributor.

## Install and connect

Browser detection supports custom installation drives through Windows registrations, PATH and running browser executables. In the Browser setup step, choose Chrome/Chromium, Edge, Brave or Firefox. If a portable or unregistered installation is missed, choose **Locate browser executable…** and select that browser's `.exe`; OneCode remembers the path separately for each browser. Selecting a browser saves it before sign-in opens. Firefox still requires the signed Companion add-on described in its setup guide.

1. Run **OneCode-Setup-x64.exe** as your ordinary Windows user. Keep its per-user install folder unless you have a reason to change it. Start **OneCode** from its shortcut. Do not use another person's development launcher or copy their application-data folder.
2. In **Setup**, select Brave or Chrome. Open its extensions page (`brave://extensions` or `chrome://extensions`), turn on **Developer mode**, and choose **Load unpacked**. Select the companion folder shown by OneCode. A fresh packaged app creates a stable copy under `%APPDATA%\OneCode\extension`; an upgrade may retain its existing GeminiCode folder. Use the path the app actually displays. Keep Developer mode on. After updating the desktop app, reload this same extension if the browser reports an old build.
3. Accept the companion's browser permission prompt after reviewing it. It uses access to the selected provider, loopback pairing and a scoped debugger rendering lease for background operation. The browser may show a debugging banner during work. Cancelling that lease can pause background progress. No CUA driver is required by the product.
4. Choose **Gemini** or **ChatGPT** in OneCode Setup, then open that provider in the selected browser using your own account. Reload the provider page after installing or reloading the Companion. One Companion contains both adapters.
5. Share a new empty scratch folder in OneCode. Fresh installations start with read permission only and workers off. Deliberately enable file changes/commands in **Workspace** only for work you authorize. Programs run as your Windows user; an approved folder is not an operating-system sandbox for shell commands.
6. In **Setup**, open **Advanced — connection, program and startup** below the step guide. Its **Connection method** selector is available from every setup step and after setup is complete. Keep **Tailscale Funnel — recommended** for a new installation. Install [Tailscale for Windows](https://tailscale.com/docs/install/windows), then use its tray icon to sign in to **your own** Tailscale account. Keep Tailscale running. In the **Connect** step, click **Connect**: its CLI, account and Funnel rows show the actual latest checks. If Funnel permission is required, follow the [official Funnel setup](https://tailscale.com/docs/features/tailscale-funnel) or ask your tailnet administrator, then retry Connect. OneCode does not sign you in or change your tailnet's access policy. It refuses to replace a conflicting existing Funnel setup.
7. Wait for an actual published HTTPS URL; with Tailscale, also wait for **Public HTTPS reachability** to pass. CLI, account and Funnel configuration checks alone do not prove that the provider can reach the service. For Gemini, add **OneCode Core** through **Settings → Connected apps → Custom**. For ChatGPT, open **Plugins → Add → Add custom MCP server**. Use the exact Core URL shown in OneCode, including its entire path. Leave OAuth client ID/secret empty for this secret-URL service. A model API key is not required for ordinary browser chats. A different account or organization can require a different setup; do not substitute somebody else's URL or credentials.
8. Return to the desktop composer and start a **fresh** chat with: `Read the approved scratch folder and tell me what is in it. Do not change files.` Confirm an actual read tool result in the app. The composer adds the native Core mention and current session binding; you do not type an @ mention each time.

**Cloudflare alternative:** select **Cloudflare quick tunnel — temporary address** under **Setup → Advanced — connection, program and startup → Connection method**. Its program is bundled and it needs no Tailscale account, but its public hostname changes whenever the connection restarts. Windows may show a firewall request for `cloudflared.exe`. The tested HTTPS tunnel continued working after **Cancel**, leaving inbound public/private network access blocked. Do not turn off the firewall. Close the prompt before continuing setup, since it can block interaction with other windows.

Each PC has its own bridge pairing, secrets and session keys. Do not share connector URLs, binding credentials, profile folders, cookies or logs containing private conversation data. Fresh installations use `%APPDATA%\OneCode`. If that folder does not exist and a previous GeminiCode profile exists, an upgrade keeps using that profile in place; it does not copy or move its secrets. Use the actual folder shown by the app, from this PC's installation and user profile.

You can switch **Settings → General → AI provider** while OneCode is running. The choice applies to new chats immediately. Existing Gemini and ChatGPT chats keep their provider identity, trust state, browser route and conversation URL, so both remain usable without an app restart or Core reconnection.

**Old embedded-browser setting:** embedded Google sign-in is not supported and cannot be selected in Setup or Settings. Google's [secure-browser policy](https://developers.google.com/identity/protocols/oauth2/policies#secure-browsers) requires a full browser. If an older profile still has the embedded setting, Setup asks you to choose **Use Brave** or **Use Chrome**. That explicit action saves the full-browser choice before opening Gemini; OneCode does not silently change it. Install the companion in that browser if needed. Keep working in OneCode; its managed chats can run in the browser in the background. OneCode does not copy Google cookies or transfer an external Google account into an embedded browser.

When signed in, **Manage Gemini accounts** opens the selected browser. Use Gemini's native profile menu to add or switch accounts. Future new chats use the selected account; existing chats keep their original account. Switching accounts or browsers keeps your local chats, shared folders and connection settings. Each Google account needs its own OneCode Core connection once, using this PC's current URL. Selecting a browser family is separate from choosing one of that browser's profiles; install the companion in the profile you use.

## Restarts and updates

Start OneCode from its installed shortcut each time. Your settings and chats stay in the same Windows user profile across app and PC restarts. **Connect automatically at startup** controls whether OneCode starts its saved connection for you; leaving it off means clicking **Connect**, without repeating setup or adding the same stable connector again.

Tailscale is the default only for **new installations**. Upgrades keep their chosen connection method. Tailscale's device hostname and OneCode's saved app/connector paths can stay the same across ordinary restarts. Changing the device name, tailnet or saved paths can change the URL; reconnect Gemini whenever the displayed Core URL changes. Tailscale mode requires OS secure storage and keeps **Keep plugin URLs across restarts** enabled. Funnel publishes this app over public HTTPS; possession of a connector URL is access to that connector, subject to OneCode's live permissions. Keep it private.

The Cloudflare quick tunnel gets a **new public hostname after restarting the connection**. Replace/reconnect Gemini's custom Core app with the new URL shown in Setup. Keeping secret URL paths does not preserve that hostname. Closing the app window normally keeps it running in the tray, while **Quit** stops it.

OneCode checks this project's GitHub Releases and downloads new versions in the background. When ready, choose **Update and restart**. If a reply, tool, queued message, terminal, worker or automation is active, it waits until that work is finished; **Cancel restart** lets you keep working. Pause Goal/Loop and close terminals when you want to restart. A normal Quit does not install a staged update. Windows uses differential downloads when the previous installer cache is available and a full download otherwise. Updates keep the current installation folder and Windows profile. After an update, reload the unpacked Companion in your browser if OneCode reports a different build.

**Upgrading from 0.2.6 or earlier:** download and install the new OneCode installer once to enable the updater. Those older versions cannot turn it on themselves. The installer retains local app data on uninstall; remove it separately only if you intend to erase your settings, plugins and history.

The update includes the Companion. OneCode maintains its stable extension folder and asks the Companion to reload after active browser work finishes. If it cannot reload automatically, a visible **Update extension** notice opens the extension instructions, including **Open extension folder**. Reload OneCode Companion on your browser's Extensions page, then refresh idle Gemini and ChatGPT tabs. If it still shows the old build, load the folder opened by OneCode; a different source/development folder cannot be updated by the installed app. A protocol or build mismatch can require this even when the displayed version numbers match.

### Compact & Resume

Choose **Compact & Resume** when a task needs a fresh conversation. Gemini writes the handoff as Markdown using the current Core `save_handoff` tool; ChatGPT uses its native answer receipt. OneCode saves and verifies the handoff before opening the next chat on the same provider. It does not need write access to your project just to save a handoff. If Core was connected before its handoff tools were added, refresh its tool list in the provider once.

Keep OneCode, its connection and the paired browser running. Recovery waits while a local tool is running or your browser composer contains an unsent draft. It verifies the current native question before refreshing, and does not resend a message whose delivery is uncertain. Previously verified native permission replies stay attached to their original task across refreshes. A handoff already stuck under an older version may need cancelling and starting again; a finished prose reply from that older attempt is not proof that a Markdown file was saved.

The context counter estimates locally recorded conversation size against your configured compaction threshold. It does not measure Google's actual model context, rate limit or remaining usage.

### Keep a stable HTTPS address with your own tunnel

This is an alternative operator setup, separate from managed Tailscale Funnel and the bundled quick tunnel. You need your own public HTTPS hostname and tunnel/reverse proxy, such as a [named Cloudflare Tunnel](https://developers.cloudflare.com/tunnel/features/locally-managed-tunnels/create-local-tunnel/).

1. In **Settings → General → For developers**, enable **Keep plugin URLs across restarts**. This preserves secret path tokens using this PC's secure storage; it cannot preserve a quick-tunnel hostname.
2. In **Setup → Advanced — connection, program and startup → Connection method**, choose **Local only — I run my own tunnel**, then connect. Read the complete current loopback Core URL shown in the app. Its port is the MCP server's port, not the companion bridge port.
3. Route your hostname to that loopback origin, preserving the full request path and streaming responses. The origin must receive a loopback `Host` header; for Cloudflare set [`httpHostHeader`](https://developers.cloudflare.com/tunnel/configuration/) to the loopback host and port shown by the app. Publish no other local services. Follow the tunnel provider's current DNS and credential setup.
4. Add the resulting **HTTPS hostname plus the exact Core path** to Gemini. After an app restart, check the loopback port and update your tunnel's origin if it changed. The hostname and saved path can stay the same; changing either still requires updating Gemini. This app does not run/manage your named-tunnel service for you.

## Plugins, Skills and modes

Choose **Plugins → Computer use → Install** to connect CUA Driver. OneCode finds existing official installations even when the desktop's PATH is stale and reuses the running daemon. If Driver is absent, it downloads the pinned installer from [trycua/cua](https://github.com/trycua/cua/tree/main/libs/cua-driver), verifies its checksum and runs the official setup. Complete any native permissions requested by Driver. Its files are installed separately from OneCode.

The same action downloads the complete official `cua-driver` skill into your local Skills library. **Skills → Computer use → Install** follows that setup too. Existing driver installations and edited skills are preserved. In a chat, ask the agent to discover Computer use through Core's `plugins` tool and read the `cua-driver` skill from `/skills/.catalog.json`. Disabling the plugin disconnects OneCode while leaving the shared daemon running for other clients.

Attach photos and files through **Add attachments → Add photos & files**, or paste a photo into the composer. CSV files are sent to Gemini as a text copy named `original.csv.txt` because the tested native CSV loader rejected ordinary CSV uploads. The bytes remain unchanged, and app history retains the original filename. Other file types still depend on Gemini's supported formats and limits.

Install plugins through this app. Enabled external MCPs are discovered/called through Core's `plugins` tool; if Core was connected before that wrapper first became available, reconnect Core once. Later plugin additions/removals use live discovery. A custom stdio server needs its executable and arguments on **this PC**, or use its supported Streamable HTTP URL and its own authentication. Another app's MCP configuration and installed services are not imported automatically. Plugins and native dependencies have their own OS/CPU requirements. npm packages requiring blocked lifecycle build scripts need an appropriate prebuilt server or a separately prepared executable; the app does not run npm lifecycle scripts during installation.

The private Node/npm bundle is an app fallback, not a global Node installation. Existing explicit executable paths remain unchanged. Development tools such as Git, project-specific SDKs, browsers downloaded by a plugin, and accounts for remote services may still need their own installation/setup.

Local Skills are listed on demand by reading `/skills/.catalog.json`; then read a returned `SKILL.md`. Later installations appear without reconnecting. These local skills are separate from the optional reusable skill saved in your Google account.

### Install the optional Gemini skill

OneCode ships the public `onecode-gemini` skill with the installer and source download. **Core works without it:** the app selects Core and supplies current tool instructions automatically. A skill does not fix “MCP server could not be reached.”

1. In **Setup → Gemini skill — optional**, choose **Save SKILL.md** or **Save skill ZIP**. The ZIP contains only `SKILL.md` at its root. It contains no connector URL, session key or Google account data.
2. Choose **Open Gemini Skills**. It opens your selected full browser. Check that this is the same Google account where you connected OneCode Core; use Gemini's profile menu to switch if needed.
3. On **Customize → Skills**, choose **Upload**, select the saved Markdown or ZIP, review the name `onecode-gemini` and instructions, then choose **Create**. Alternatively, create a skill manually with that name, describe it as “Use OneCode's connected tools for coding and workspace tasks”, and paste **Copy instructions** into its Instructions field.
4. Activate the saved skill in Gemini. Then enable **Use Gemini's onecode-gemini skill** in OneCode Setup and start a new chat. Exporting a file, copying text or checking this option does not install a skill in your account. Repeat the Gemini import for each Google account you use.

Google controls Skills availability and requires Keep Activity to be on. If your account has no Skills page or upload option, leave the option off and use Core normally. The bundled file is also available at `resources/skills/onecode-gemini/SKILL.md` in the public source. If you installed earlier Gemini guidance, import the newly named onecode-gemini skill before enabling this option. Follow [Google's current skill creation and upload instructions](https://support.google.com/gemini/answer/17094296?hl=en) if its buttons change.

**Goal** continues toward the saved objective and can stop when it is satisfied. **Loop** continues until paused; automatic pickup pauses if the exact source turn contains no local MCP tool call. **Plan** drafts editable workflow stages, sends the complete request/workflow first, then queues verification checkpoints. The default browser helper needs no API key. Choosing an API continuation backend requires its own configured provider credential (a keyless custom local endpoint is also supported). Native model availability, message limits and approval controls remain Google's.

## Troubleshooting

### Automatic Tailscale setup and recovery

OneCode detects the system Tailscale executable, including normal per-user installations, and configures its own routes. After an installation or account prerequisite is fixed, it checks again and continues automatically. It opens the required Tailscale setup page once; the same action and an expandable **Setup recovery steps** guide remain in Setup and Remote settings.

1. Keep Tailscale running and connected using your own account. If its Windows service is stopped, open PowerShell as Administrator and run `Start-Service -Name Tailscale`.
2. If OneCode reports MagicDNS or HTTPS approval, open the [Tailscale DNS console](https://login.tailscale.com/admin/dns), enable **MagicDNS**, then enable **HTTPS Certificates** and approve Tailscale's certificate notice. A tailnet administrator may need to do this. OneCode detects approval automatically.
3. A provider connector needs **public Funnel**, including the tailnet's Funnel permission. Private Serve by itself cannot make a connector reachable by Gemini's servers. OneCode verifies public DNS, TLS, the exact connector metadata and MCP initialization before making its connector link ready. Wait for these checks; then copy the current Core URL into the provider. [Funnel setup](https://tailscale.com/docs/features/tailscale-funnel).
4. Browser Remote uses a separate **private Serve** route. Turn on **Settings → Remote**, then copy its link to another device connected to the same Tailscale account. OneCode chooses a free port and preserves unrelated routes. Tailnet policy must allow access between the devices.
5. If automatic setup cannot finish, follow the numbered in-app recovery guide. `tailscale status`, `tailscale serve status` and `tailscale netcheck` help identify sign-in, route and network problems. If the executable is not on PATH, use the full path detected in OneCode's Advanced settings.

Tailscale normally needs no manual firewall change. For restricted networks, the recovery guide includes a copyable Administrator PowerShell command that locates the installed Tailscale service and permits its default direct tunnel on UDP 41641, scoped to that service executable. Use the configured port instead if its default was changed. It does not open OneCode's loopback HTTP listener or disable the firewall. A network that restricts outbound traffic must permit Tailscale's TCP 443 and UDP 3478 traffic. [Official firewall guidance](https://tailscale.com/docs/reference/faq/firewall-ports).

- **No tools / disconnected:** check the app connection, current Core URL, selected signed-in browser profile and companion build. Full access in OneCode and attachment of its Core connector in the provider are separate requirements. Core's live `plugins` discovery now returns built-in file, terminal and canvas methods too, so an existing chat can discover newly enabled commands without relying on its cached direct schemas. ChatGPT refuses an ordinary tools-enabled Send if this installation's required Core cannot be attached. Native image generation keeps its separate tool-free path.
- **Cloudflare:** an assigned quick-tunnel URL is checked with a public MCP initialization before OneCode reports Connected, then rechecked periodically. Its current URL must be the one saved in the provider connector; quick-tunnel hostnames change when restarted. On restricted networks, allow outbound port 7844 over UDP (QUIC) or TCP (HTTP/2), as described in [Cloudflare's firewall guidance](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/tunnel-with-firewall/). A valid URL alone does not prove the origin is reachable or its connector is selected in the provider.
- **Tailscale cannot connect:** read the actual check rows in Setup, including **Public HTTPS reachability**. Public DNS can take about 10 minutes to become available after first enabling Funnel. OneCode checks this device's hostname through Cloudflare and Google public DNS; connector paths and session keys are not sent to DNS. It verifies the exact connector metadata and MCP handshake through the public ingress with normal TLS validation. This is separate from installing the connector in the provider. After a cold boot or network change, read-only daemon failures and transient startup states retry automatically. Existing routes and URLs are retained during network recovery. A changed route, device identity or denied permission remains an actionable error. Install or sign in using Tailscale itself, keep its service running, and ask the tailnet administrator if Funnel is restricted. Do not reset somebody else's Funnel settings or disable secure storage to bypass a conflict.
- **Remote on a hotspot:** keep Remote mode enabled on the host and Tailscale connected on both devices. A browser-level timeout before OneCode loads requires restoring network reachability and reloading the saved bookmark. Complete any hotspot/captive-portal sign-in; a carrier or firewall can block traffic OneCode cannot bypass. Once loaded, stalled reads or initial connection attempts time out after 30 seconds and offer Reconnect. Longer submitted operations have a 120-second request limit and are never automatically resent. A transient host daemon outage temporarily disables Remote admission; the watcher verifies the same retained private route before restoring access. Reopening the bookmark renews browser admission without changing the saved link. See [Tailscale captive portal guidance](https://tailscale.com/docs/integrations/captive-portals).
- **A plugin fails to start:** check that its host program is installed and the executable/arguments are valid on this PC. npm plugins have a private fallback runtime; reinstall OneCode if its bundled runtime is missing. Remote services can require separate sign-in.
- **Uploads or a mode stalls:** keep the paired browser running, inspect the app's queued delivery/error and Gemini's actual state. Refresh only when no ambiguous send is pending. Do not repeatedly resend an operation whose receipt is unknown.
- **Window minimizes unexpectedly:** this app has no minimize-on-Send preference. Preserve the event time and share the content-free `main window presentation` / `main window send` diagnostic rows with the distributor. Do not treat a forced restore as a fix.

Reference: [Google custom connected app setup](https://support.google.com/gemini/answer/17209137?hl=en), [Tailscale Windows installation](https://tailscale.com/docs/install/windows), [Tailscale Funnel](https://tailscale.com/docs/features/tailscale-funnel).
