# OneCode 0.9.2

OpenRouter chats accept photos, PDFs, UTF-8 text and code files, WAV and MP3 audio, and MP4 and WebM video. The model picker shows catalog input capabilities. Photos require vision, and audio and video require the matching input modality. PDFs use native file input when advertised and OpenRouter’s Cloudflare parser otherwise. Photos are resized for delivery. API attachments share a 3 MiB encoded budget per message, with up to 128 KiB of text files.

Claude delivery now reads the exact native question across split attachment layouts and commits the receipt before flushing transcript updates. A complete matching app-authored body can be recovered when Claude collapses whitespace during the owned Send. A reply alone supplies no delivery receipt.

Stable API delivery messages use channel-neutral wording. See [release validation](../release-acceptance/v0.9.2.md).
