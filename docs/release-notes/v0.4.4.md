# OneCode 0.4.4

The existing **What's new** pane now has highlights for current OneCode releases. It opens once after updating and restarting, waits until another open dialog closes, and links to the exact installed version's GitHub release. Reopen it under **Settings → General → What's new → View changes**. Close it with Got it, Escape or the backdrop.

This is the first application hotfix release for compatible Windows x64 installations on 0.4.3. Use **Settings → General → Check for updates → Install when done**. The updater verifies the application bundle, waits for active work to finish, applies it and restarts. No complete installer is uploaded for this release. Profiles, chats, connector URLs and the native runtime are retained.

New users and users on 0.4.2 or earlier first install the [0.4.3 base release](https://github.com/hassanradwannn/OneCode/releases/tag/v0.4.3), then use its internal updater. Incompatible native runtimes require that complete base installer. Do not manually extract the hotfix into an installation.

Included from earlier releases: slower valid public HTTPS/MCP replies can complete, timeouts are distinct from TLS failures, public DNS checks work with either supported resolver, and explicit Windows public-connection repair preserves the existing routes and saved URLs. These changes do not guarantee upstream network availability.

See the [acceptance record](../release-acceptance/v0.4.4.md) and [hotfix guide](../HOTFIX-UPDATES.md).
