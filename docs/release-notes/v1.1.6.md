# OneCode 1.1.6

- A request for a copyable Markdown file guides the model to save a regular `.md` file and link it in the reply. Linked workspace documents open in the sidebar. **Copy Markdown** copies the original source.
- Replies support labeled web links and workspace file links. A workspace link uses the recorded assistant message and the installation's approved file access.
- Completed turns show recorded file changes under the final reply. **View changes** or a file row opens the saved diffs, with separate snapshots for repeated edits.

This Stable release provides a Windows x64 installer, Linux x64 AppImage and DEB, and compatible application capsules. The capsules retain the Windows 0.5.9 and Linux 1.0.7 minimum complete bases.
