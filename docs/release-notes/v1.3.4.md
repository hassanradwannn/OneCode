# OneCode 1.3.4

## Sub-agent startup

- New ChatGPT workers that request a reasoning effort use the native default model group. When the requested effort is already selected, OneCode leaves the model picker closed.
- The Companion waits for the current composer to become writable after a model change, even when ChatGPT keeps the old editor mounted or assigns the new editor’s ID later. It sends the task only after the original worker’s tab and draft still match.
- Expand the parent chat to see workers that are opening or failed to start, alongside workers with saved conversations.

## Install or update

On Windows or Linux x64, open **Settings → General → Check for updates** and select **Install when done** when the download is ready. For a fresh installation, start with the complete 1.3.0 package and then check for updates. [OneCode 1.3.0 installers](https://github.com/hassanradwannn/OneCode/releases/tag/v1.3.0)
