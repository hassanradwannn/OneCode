# OneCode 0.7.2

Stable 0.7.2 includes the long-session and delivery repairs developed through Beta 0.7.27, plus browser recovery and setup improvements.

- Companion fallback wakes stay armed during stalled maintenance and startup. A bounded read-only tab query cannot pin maintenance indefinitely or turn an unknown tab list into an empty one.
- MCP tool responses send keepalives during exact task admission as well as execution, for both providers. Closing the request before admission prevents later tool dispatch; uncertain mutations are never replayed.
- Temporarily unavailable exact session records remain pending instead of permanently invalidating input and resumed-task grants. Changed questions, Block, cancellation, revoked grants and foreign sessions still refuse execution.
- Explicit ChatGPT Steer recognizes fully uploaded attachments even while Stop remains visible, spends one guarded native Stop when Send is unavailable, and then obtains normal Send authorization and an exact receipt. Cancellation, approvals and changed drafts remain fences.
- The selected-chat tool caption uses the current conversation and exact active turn. Finished or predecessor-chat work cannot present itself as the current running tool. Stale Steer selection preserves the authored follow-up through the Beta admission repair.
- Tailscale setup links directly to DNS and Access controls and identifies the Funnel policy action. Established connectors stay visible during the existing transient-check retry window, with a warning; first-time setup still requires verified public DNS, TLS and MCP readiness.
- Exact durable delivery acknowledgements clear stale selected-chat readiness warnings. Long-session, Steer, late receipt and grant-retention repairs from Beta are retained.
- Release assets include the canonical cross-platform checksum register. Compatible application capsules use the verified Stable 0.5.9 bases for Windows and Linux; older incompatible installations retain the existing verified base-upgrade behavior.

Validation: focused local regressions and public source verification; GitHub builds and packaged smoke are recorded with the release run. Signed-in native acceptance and installed-updater acceptance of 0.7.2 were intentionally deferred at the maintainer's request. Earlier Beta evidence is not claimed as native acceptance of this release.

## First-time Tailscale setup

**First-time Funnel setup: allow up to 15 minutes before troubleshooting an initially unreachable connector.** Tailscale documents that public DNS propagation can take up to 10 minutes; 15 minutes is a practical first-setup allowance, not a guaranteed tunnel-issuance time. During that interval, Tailscale can look connected locally while ChatGPT or Gemini still cannot reach the public MCP URL. Keep OneCode and Tailscale running. OneCode keeps checking automatically; wait for the public DNS, HTTPS and MCP checks to pass before creating or retrying the provider connector. If it remains unreachable after that allowance, inspect the specific check and permissions instead of assuming every failure is propagation. [Tailscale DNS propagation guidance](https://tailscale.com/docs/features/tailscale-funnel#dns-propagation).
