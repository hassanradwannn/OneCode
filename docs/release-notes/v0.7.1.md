# OneCode 0.7.1 Beta candidate

Explicit Steer retains its exact recorded source question when the provider virtualizes that question's native row. The same published question, current turn, conversation and document must still agree. A visible different question, pending identity adoption, changed route, user draft or refused Main claim prevents Send. This does not change Stop or automatic recovery evidence.

Companion diagnostics now expose bounded maintenance and input-pickup stages without task text, credentials or private addresses. Diagnostic requests can report a blocked maintenance stage independently of that maintenance flight.

This candidate is for native delivery acceptance. Stable 0.7.0 remains unpublished while the observed native queue and live-Steer failures are investigated.
