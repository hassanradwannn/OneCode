# OneCode v0.3.0

OneCode is a desktop workspace for AI providers with local MCP tools, managed chats and parallel agents.

- Fixed signed-in account detection in the browser companion. A provider composer alone no longer counts as a signed-in account.
- Settings, setup and companion controls use provider-neutral wording. Provider choices and model names retain their actual identities; user text and connector names are preserved.
- MCP initialization publishes the configured connector name exactly. Native connector selection accepts a unique presentation change in capitalization, spacing or dashes for that configured device; ambiguous or different device names are refused before Send.
- Added narrowly scoped automatic dismissal of the recognized English response-comparison feedback panel. It requires the comparison heading, both options and the isolated feedback footer; it never uses a general Skip search or stops thinking.
- Preserved independent provider listeners, credentials, chat ownership and model catalogs, with Tailscale and Cloudflare connection options.
- Included the updater publisher configuration and Windows shortcut repair. Check for updates is available in Settings; app and companion versions are both 0.3.0.

Validation: TypeScript, production build, packaged Windows native-runtime smoke, 421 focused regression checks, and real MCP initialization checks for both providers passed. The companion sign-in repair was also observed on the laptop without signing in again. Both providers previously completed real tools in parallel and the user reconfirmed parallel use and persistence.

The comparison guard has structural DOM regression coverage; a fresh live comparison panel has not yet been observed. Fresh long Goal Loop, Plan and compaction runs remain outside this acceptance pass. Current native ChatGPT calls do not always carry a reliable conversation identifier, so some local tool records can remain unattributed; no identity is guessed.

Install the Windows x64 setup from this release, or use Settings → Check for updates on an installation with updater metadata. Some older 0.2.9 packages omitted that metadata and need one manual installation. The previous display version 0.2.9.5 used the compatibility package/tag 0.2.905; this release uses 0.3.0 consistently.
