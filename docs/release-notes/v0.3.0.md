# OneCode v0.3.0

OneCode is a Windows desktop workspace for Gemini and ChatGPT with local MCP tools and managed chats.

- Fixed same-provider input blocking: work in one chat no longer holds ordinary prompts in another chat. Update and compaction safety barriers still account for all running local work.
- Fixed companion recognition of configured OneCode connector names and device suffixes. ChatGPT uses its own endpoint and does not request Gemini session credentials.
- Fixed Gemini follow-ups retaining a completed opening's claim, and recognized the compact native model control's explicit accessibility label.
- Verified separate file attachments and correct file contents in concurrent chats. Attachments retain their originating chat's custody.
- Included account sign-in detection, provider-neutral setup, configured connector naming, bounded response-comparison dismissal, Windows version resources, updater publisher configuration, and shortcut repair.

Validation: 568 focused regression checks, TypeScript, production build, Windows packaged native-runtime checks, and an actual upgrade/relaunch of the normal desktop profile passed. Live signed-in checks exercised two ChatGPT chats and two Gemini Flash chats, uploaded distinct files, verified their contents, and completed a second chat while a local command ran in the first. Existing history and connector URLs were preserved.

Provider limits still apply. Flash-Lite reported a tool-call limit in one test; the full Gemini overlap check used Flash. Some native ChatGPT tool records can remain unattributed when the provider supplies no reliable conversation correlation. No conversation identity is guessed. Fresh long Goal Loop, Plan, and compaction runs are outside this acceptance pass.

Future work now explicitly includes provider-native outputs reaching OneCode, starting with displaying and saving images generated by Gemini. This release does not claim Gemini native image export is implemented.

Install the Windows x64 setup, or use Settings → Check for updates. Older builds that omitted updater metadata need one manual installation. App and companion versions are 0.3.0; update both together.
