# OneCode 0.8.5

Windows network repair is always accessible when Tailscale is the selected connection method.

- Find **Fix network** in the connection popover and Setup while disconnected, connecting, connected or reporting a network error. The action no longer depends on one specific public TLS verdict.
- Restart the Windows Tailscale service through the normal administrator consent prompt, including when startup cannot reach its daemon. Saved URLs, sign-in and Serve/Funnel routes are retained.
- Keep one repair in flight across repeated clicks and status repaints. Running tools and a closing or changed connection remain protected. Cancellation does not automatically retry the restart.
- Recheck exact route ownership and public reachability after an active connection's repair. Restarting the service alone does not declare the connector healthy or recreate a replaced route.

This cumulative application hotfix includes Stable 0.8.4's fixes and updater progress bar/MB display. Windows capsules remain compatible with the complete 0.5.9 base, and Linux capsules with 0.8.2; the native runtime is unchanged. This release contains application capsules, not new full installers. Fresh installations can use the complete [0.8.4 release](https://github.com/hassanradwannn/OneCode/releases/tag/v0.8.4) and then update normally.
