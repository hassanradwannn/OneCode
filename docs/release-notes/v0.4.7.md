# OneCode 0.4.7

Windows x64 application hotfix using the complete 0.4.5 native base.

- Fix steering that successfully sends a correction after Stop but loses the new working turn and tool authorization. The Send owner and observer now use the same previous native-message identity even while its text is temporarily unreadable.
- Restore the normal no-progress recovery window to 90 seconds. A confirmed app-authored ChatGPT input can receive one exact-question refresh before its first tool call; it no longer falls outside recovery merely because tools have not started.
- Keep existing progress, newer-question, Stop, permission, running-tool and recovery-Off checks. A refresh alone does not authorize another Send. Gemini's first-response floor and Pro/deliberate-thinking windows remain longer.
- Update the paired Companion recorder and show these repairs in What's new. Earlier hotfixes remain included.

Use **Settings → General → Check for updates → Install when done**. Compatible installations receive the smaller application capsule. The complete base remains [0.4.5](https://github.com/hassanradwannn/OneCode/releases/tag/v0.4.5); older updaters unable to offer a capsule should install that base, then check again. Chats, permissions and connector URLs are preserved.

See the [acceptance record](../release-acceptance/v0.4.7.md) for reproduction, tests and native acceptance limits.
