# OneCode 0.7.0

This release brings the reliability repairs developed since Stable 0.6.17 into one Stable update:

- Explicit native Steer retains the original local process and its output while the new question receives its own exact task receipt. Preparing the next input preserves authorization for already admitted calls.
- Gemini model preparation follows its own native header/control replacements while preserving the selected model, draft and deadline. Native approvals match the configured connector and enabled tool names.
- Connection notices and silence warnings cannot end a running task. Companion restoration, composer text with connector chips and restart recovery retain their original delivery and task owners.
- Failed automatic-message notices can be dismissed without deleting delivery evidence. A later confirmed question clears an old failed-handoff composer badge while its saved summary remains available.
- Mermaid artifacts render offline with editable source and existing exports. Plugin discovery is redacted and bounded, with exact schemas retrieved separately.
- Compatible updates retain the installed native base, user profile and saved chats on Windows and Linux.
