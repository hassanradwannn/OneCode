# OneCode 1.1.0

- Capture ChatGPT visual styling from the mounted native response, including class-based spacing, rounded corners, typography and SVG paint.
- Preserve responsive authored dimensions in the offline snapshot. Media and portable reply controls retain their existing import owners.
- Show surrounding prose without pasting an imported visual's labels into the transcript a second time. Full canonical text remains available for copy and export.
- Fit native visual previews to their content height, with bounded scrolling for tall content and the existing fullscreen and viewport controls.
- Require exact native message ownership before importing or removing a visual from its display capture. Updated Companion readers replace the prior pair together.

Complete Windows x64 installers and Linux x64 AppImage/DEB packages accompany cumulative application capsules. Windows capsules use the verified 0.5.9 complete base; Linux capsules use 1.0.7. Internal updates retain the platform's native compatibility checks and preserve the existing profile.

Offline previews retain standard HTML controls and supported bundled artifact runtimes. Provider-only event handlers and services still require the original provider chat; this release does not claim universal behavior parity for those controls.
