# OneCode 1.3.3

## Handoffs and file review

- Copy a ChatGPT Writing card even when the browser capture lost its Copy control. OneCode uses the exact Writing Markdown saved in that reply.
- Open the files named in the final reply. OneCode verifies supported paths against the chat’s approved workspace, opens Markdown with a **Copy Markdown** action, and offers downloads for ZIPs.
- When a turn completes while you are viewing it, OneCode opens its single linked Markdown document if that turn recorded an edit to it. Older replies also gain file links when the referenced files are still available.
- Scroll through recorded changes in a full-height diff pane.

## Install or update

On Windows or Linux x64, open **Settings → General → Check for updates** and select **Install when done** when the download is ready. For a fresh installation, start with the complete 1.3.0 package and then check for updates. [OneCode 1.3.0 installers](https://github.com/hassanradwannn/OneCode/releases/tag/v1.3.0)
