# OneCode 0.5.2 — reliability repair candidate

This candidate carries the reliability repairs exercised in the isolated 0.5.1 Beta test base, plus the provisional-chat classification repair found during native acceptance. Stable publication remains gated on installed update acceptance.

- Preserve exact task and Remote authorization across ordinary reconnects, sleep and restart.
- Retain completed command output independently of live process capacity, expose background work per process, and stop commands owned by an explicitly stopped chat. WSL descendants retain exact run and process identity.
- Offer **Update now** and **Install when done**. Installation waits for verified shutdown and saved output.
- Support Linux AppImage full internal upgrades and compatible application hotfixes on AppImage and DEB. A missing required AppImage base and cumulative hotfix are verified together before one successor launch. Full DEB/native upgrades remain package-manager owned.
- Isolate unpacked QA and Beta profiles and single-instance locks from production. Beta uses its own internal release and hotfix feed.
- Preserve the chosen browser and exact chat ownership through opening, Stop, Continue and Compact & Resume. Uncertain Send and tool operations are not replayed automatically.
- Use the connector name configured in Setup for selection and automatic approval. Stable has no dependency on a connector named Beta.
- Keep a locally authored new chat separate from genuinely unattributed activity while its native conversation is still opening. Its menu cannot change global unattributed-call policy.
- Center the background-work dialog, retain commentary revisions, and link release notes to the installed channel's exact version.

## Updating

The Linux bootstrap and profile-isolation changes require a complete new AppImage or DEB base. Later compatible application capsules update internally. Profiles, projects, chosen browser, connector settings and saved chats are retained.

The acceptance record distinguishes source and package checks from real installed full-update, hotfix and combined-update checks.
