# OneCode 0.6.9 Beta candidate

Released steering inputs now use the same live outbox policy for browser offers, claims and final Send authorization. A local poll can remain open after the provider stops its response without blocking that same steering input. The Companion forwards the steering source and no longer uses cached activity counts to veto eligible input. Native generation, changed questions, draft custody and uncertain Send receipts remain guarded.

An explicit manual follow-up can use a confirmed native completion while local work continues. An immediate message held by the live input policy retains its original outbox row; its browser pickup timeout resumes only when it is eligible. Automatic continuation keeps its settled-work checks. Continuation Stop can recognize the exact native interrupted response without requiring a final assistant message, and still checks the redeemed question. Steer preserves local processes; explicit Stop retains exact-session termination.

Recorder revision 74 replaces older content closures. Bridge protocol 19 is unchanged. This candidate includes the earlier Gemini preparation, recovery, startup, Companion coexistence, host routing and recorded-file repairs. Native Windows/Linux, ChatGPT/Gemini, Desktop/Remote and installed updater acceptance remain release gates. This candidate is not a stable promotion; the overnight Windows crash cause remains unproved.
