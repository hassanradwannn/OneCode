# OneCode 0.4.2

Windows x64 hotfix for a connector whose local service works while Tailscale's public TLS path has stopped accepting connections.

**Settings → Connection → Repair public connection** now offers recovery after that exact failure. OneCode verifies its current native route before requesting Windows administrator consent to restart Tailscale. The restart briefly interrupts Tailscale connections and preserves saved routes, connector URLs, account state and chats. Repeated clicks share one action; automatic checks never launch administrator prompts or replay a cancelled repair.

A failed public check now shows Checking rather than remaining Connected during the retry window. After a repair, only a new public DNS → verified HTTPS → MCP check can restore Connected. Actual provider tool use remains a separate check.

This shared Windows recovery covers both ChatGPT and Gemini connectors. The 0.4.1 DNS fix remains included. Update through **Settings → General → Check for updates → Install when done**, then use Repair public connection if a public TLS failure recurs. No connector deletion or sign-in reset is required.
