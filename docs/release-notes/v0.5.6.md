# OneCode Beta 0.5.6

This candidate repairs terminal result delivery, worker reuse, Stop, folder grants and Remote conversations.

- Completed command and poll output is bound to its response receipt so acknowledged results stop blocking new commands. Raw and displayed batch output use matching cursors; older affected results are restored without replaying commands or deleting their bytes.
- Shutdown fences pending terminal launches and bounds simultaneous Windows process-tree stops. Native Stop acknowledgements remain pending until the exact provider turn ends; stopped workers remain reusable after revival and parent-chat handoff.
- Folder-picker grants publish immediately. Standalone explicit written folder approvals in desktop and authenticated Remote messages use the same grant owner; attachments, quoted documents and model tool text cannot grant access.
- Remote loads earlier history while scrolling upward, previews image attachments with a separate remove button, closes the attachment picker after selection, and groups workers beneath their parent.
- Journal open failures receive bounded safe retries and a useful recovery message. An unreadable journal cannot replace its metadata checkpoints with an incomplete reconstruction; the desktop offers Reload chat after a failed history read.

Candidate acceptance is recorded separately. A persistent operating-system access denial still requires its actual file-access cause to be resolved; no security protection, chat history or unrelated process is reset by these repairs.
