# OneCode 1.0.81

- Preserve ChatGPT-generated grids, diagrams, SVG content and standard HTML controls in a safe offline artifact preview instead of flattening their layout into transcript text.
- Capture declarative visual surfaces generically without hardcoded labels, chart schemas or generated values.
- Restore a direct application update for installations using the compatible OneCode 0.5.9 complete runtime base. OneCode 1.0.8 incorrectly required the newer 1.0.7 complete base even though its native runtime was unchanged.

Windows and Linux x64 application capsules are included. Provider scripts, external resources, event handlers and network access remain outside the preview sandbox.
