# OneCode 0.6.13 Beta candidate

Windows shutdown could report an unfinished WSL obligation after concurrent completion capture had already proved that exact token empty and retired it. Shutdown now checks the same canonical custody store after all termination attempts settle. A stale result cannot manufacture remaining work; a retained token, changed store or unconfirmed Windows process exit still blocks the update handoff. No process identity, cancellation proof or storage guard is bypassed.

Includes the 0.6.12 long resumed-task authorization repair and earlier Steer and follow-up repairs. Bridge protocol 19 and recorder revision 75 are unchanged. Installed capsule and native provider acceptance continue on Windows and Ubuntu. Stable remains gated on acceptance.
