# OneCode 1.1.1

- Keep imported browser visuals at their exact positions between the surrounding paragraphs on Desktop and Remote.
- Replace a native visual's display fallback with its saved preview once ready, instead of also appending the same visual after the answer. Canonical text remains available for copy and export.
- Compact long native replies without flattening their semantic markup, code or visual positions.
- Exclude document-reference popovers and decorative reference icons from visual capture. Public internet document links remain ordinary links. OpenRouter references and Core artifact behavior are unchanged.
- Preserve imported controls and preview state when Remote polls an unchanged history.
- Retire the display of earlier reference-chip false positives under an exact complete native visual inventory, while retaining their original records.

This cumulative application update uses the compatible Windows 0.5.9 and Linux 1.0.7 bases. Existing installations update internally. Fresh installations can use the complete 1.1.0 package and update to 1.1.1. The published 1.1.0 source and assets remain unchanged.
