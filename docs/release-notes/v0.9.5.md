# OneCode 0.9.5

- OpenRouter shows a running Vite site in the owning chat’s Workbench. A supported standalone Vite build appears as an inline artifact from the actual build files. Workbench reuses a tab for the same chat and local URL.
- The Companion adopts OneCode’s dedicated browser window when Brave starts, then reuses it for new chats and parallel work. Explicit Open reveals the same managed window.
- Imported image cards retain their images and captions. Native code blocks retain whitespace and copy locally. Open original is available when a provider action requires data outside the capture.

The release includes Windows x64 and Linux x64 installers plus compatible application updates.
