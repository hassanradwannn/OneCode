# OneCode 0.9.7

- Use **Import HTML artifact** in the desktop attachment menu to display an existing standalone HTML file directly in chat. Agents can pass the same file path to the artifact tool.
- Artifact guidance now sends agents directly to the finished file. Context handoffs ask for the source path and any pending presentation ID so work can resume from disk.
- The OpenRouter effort slider is back in Desktop and Remote. It uses the levels reported for the selected model and shows **Provider default** when no effort was recorded.

Windows and Linux x64 installers and compatible application updates are included.
