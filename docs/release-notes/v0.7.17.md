# OneCode Beta 0.7.17

Repairs current ChatGPT reply ownership when a native section remounts after the exact message acknowledgement but before the first completed reply. Recovery uses the existing owned receipt, current document and conversation, full submitted body, stable native user order and verified prior source identities.

Prior messages retain their owners; unknown or newer users, changed bodies and foreign views cannot borrow the acknowledged message. Compact and Resume retains its completed-reply proof requirements.
