# OneCode 1.4.3

ChatGPT image uploads can take up to ten minutes while OneCode keeps the original send pending. After the attachments are ready, OneCode selects the requested model and reasoning effort and checks them before sending. If it cannot confirm the upload or the settings, it leaves the prepared draft in ChatGPT for review.

## Install or update

On Windows or Linux x64, open **Settings → General → Check for updates** and select **Install when done** when 1.4.3 is ready. For a fresh installation, start with the complete 1.3.0 package and then check for updates. [OneCode 1.3.0 installers](https://github.com/hassanradwannn/OneCode/releases/tag/v1.3.0)
