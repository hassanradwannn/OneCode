# OneCode 0.9.9 Beta

Setup's provider picker and OpenRouter key form stay reachable. API setup uses the saved secure key rather than browser/tunnel status, and hidden steps no longer keep completion or navigation stuck. Next from API setup and Back from Folder follow the visible route. Switching providers keeps the matching provider page open.

A visible **Back to chats** action leaves Setup at any time, including when setup is incomplete. It preserves settings, keys, permissions and existing chats.

This prerelease retains the earlier API harness, Claude attachment handling, topic naming and sidebar browser work. Stable 0.8.9 stays unchanged and unfrozen pending user testing. Real-provider and installed updater acceptance remain pending.
