# OneCode 1.1.2

- Read Gemini's native model choices in both menu-item and radio-item picker layouts. Native mode IDs are bounded opaque identifiers, without a model-name or version allowlist.
- Retain both purpose and model captions in the newer Gemini picker, and confirm the selected native row against its observed captions.
- Refresh model catalogs older than fifteen minutes when opening the Desktop or Remote model picker for ChatGPT, Gemini, Claude and OpenRouter. Recent failed checks cool down, and explicit Refresh remains available.
- Preserve exact selected model intent across a catalog rename. Locked rows, ambiguous names and an unproved native selection remain unavailable.
- Replace the Gemini adapter/recorder pair in already-open pages through the existing Companion revision guard.

This release includes complete Windows x64 and Linux x64 AppImage/DEB packages for fresh installations, plus cumulative application capsules using the compatible Windows 0.5.9 and Linux 1.0.7 complete bases. Existing compatible Stable installations update internally with the smaller capsule. Published earlier tags and assets are unchanged.

The local provider/model suite passed 623 tests. The final refresh-specific suite passed 79 overlapping tests. Public verification and production Desktop/Remote builds passed. GitHub builds, payload verification and native acceptance are recorded separately in the [acceptance record](../release-acceptance/v1.1.2.md).
