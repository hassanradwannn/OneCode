# OneCode 1.3.6

## ChatGPT turn and task recovery

- Recover an acknowledged Steer when OneCode is still tracking the preceding turn. The Companion checks the saved Send receipt against the current ChatGPT question or response and records the missing transition without resending the message.
- Validate authorization for that exact question through the existing task grant. Once ChatGPT finishes, OneCode records the final reply and retires the active status.

## Install or update

On Windows or Linux x64, open **Settings → General → Check for updates** and select **Install when done** when the download is ready. For a fresh installation, start with the complete 1.3.0 package and then check for updates. [OneCode 1.3.0 installers](https://github.com/hassanradwannn/OneCode/releases/tag/v1.3.0)
