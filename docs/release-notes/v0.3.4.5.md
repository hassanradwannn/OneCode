# OneCode 0.3.4.5

Compact & Resume handles tool-result receipts from responses already split across several native sections. A failed pre-Send barrier releases its ticket, and an unsent automatic ticket no longer renews an exhausted reload budget. An already dispatched handoff retains its original receipt and cannot be resent automatically.

Compaction now sends the source document's actual provider at every browser checkpoint. Previously a ChatGPT handoff was incorrectly marked as Gemini and rejected before Send. Waiting-state failures remain visible, and the updated recorder replaces older retained page instances.

Gemini's MCP handoff save leaves the replacement-tab offer for its owning browser. The tool reply no longer consumes and discards a page-only opening instruction, which previously forced a delayed operating-system fallback.

Resume treats Gemini's current-model compatibility option as Automatic, matching ordinary new chats. Explicit model and reasoning choices retain their selection checks.

Gemini Resume also supplies the conversation created by its verified initialization at the destination permission checkpoints. The bridge no longer rejects that prepared conversation as an unexpected route. A replacement that fails before dispatch reports the failure instead of leaving Compact & Resume waiting indefinitely; an uncertain dispatch is still never replayed automatically.

The context meter identifies its configured value as a OneCode reference. Estimates can exceed 100% without blocking messages or tools. History-load HTTP 429 notices describe OneCode's retry wait rather than claiming the model reached a context limit. Shared status messages use provider, agent or chat, including recognized notices in saved history.

ChatGPT steering retains immediate delivery eligibility when activity loses its model label but the exact current turn still has a verified non-Pro selection. Missing selection and positive Pro evidence retain their existing guards.

The displayed version is **0.3.4.5**. Windows, Companion and updater metadata use compatibility version **0.3.405**, following the existing patch-version scheme. Windows x64 users can update internally; normal profiles and recorded history are preserved. Native dependency versions are unchanged from 0.3.4.

The intermittent Windows minimization reported with Enter is not claimed fixed by this release.
