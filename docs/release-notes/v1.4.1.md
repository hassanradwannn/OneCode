# OneCode 1.4.1

Completed replies can show **Workspace files** even when the agent leaves out the links. OneCode uses recorded file changes and can recover a Markdown link when a later reply verifies the same file from an earlier completed turn. The file opens in the sidebar, where **Copy Markdown** copies the original source.

## Install or update

On Windows or Linux x64, open **Settings → General → Check for updates** and select **Install when done** when 1.4.1 is ready. For a fresh installation, start with the complete 1.3.0 package and then check for updates. [OneCode 1.3.0 installers](https://github.com/hassanradwannn/OneCode/releases/tag/v1.3.0)
