# OneCode 0.9.1

Opening or sending an API chat no longer launches a provider browser tab. API messages stay with the local API runner while waiting for model information, preparing a request, resuming saved state or receiving a response.

OneCode now excludes API messages from the native browser-delivery queue, browser claims and Companion opening-lease projection. The Companion separately rejects API and unknown-provider offers, including unrecognized conversation namespaces, before querying, reusing or opening tabs. This also protects against a stale offer from an older app process.

ChatGPT, Gemini and Claude browser chats retain their native delivery path. Explicit sidebar website browsing remains available through its own tools; API chat creation does not open a provider site. All Stable 0.9.0 fixes are retained.

Complete Windows x64 and Linux x64 AppImage/DEB artifacts and compatible application capsules are included. See [validation and release receipts](../release-acceptance/v0.9.1.md).
