# OneCode 1.1.8

- Compact & Resume can collect an exact completed ChatGPT response when its visible reply item is slow to report completion. Recovery keeps healthy handoff streams running and preserves the original Send receipt.
- The Desktop composer keeps the delivery choice and target turn from the moment you submit. Its delivery menu shows the actual mode when files are attached.
- Eligible queued messages have a **Steer** action during an unfinished turn and **Send now** when the chat is idle. Both actions use the same queued message and keep its attachments. Click an image in the queue to preview it.

This Stable application update covers Windows and Linux x64. Its compatible complete bases are Windows 0.5.9 and Linux 1.0.7. [Complete packages for fresh installations](https://github.com/hassanradwannn/OneCode/releases/tag/v1.1.6).
