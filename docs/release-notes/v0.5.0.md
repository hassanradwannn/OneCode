# OneCode 0.5.0

Full Windows x64 and Linux x64 release. This is the first complete Linux base that can consume verified application hotfixes on AppImage installations; existing Linux builds must install the full 0.5.0 AppImage or DEB first.

- Ship Linux x64 as both AppImage and DEB with the same Core connector, Companion, managed chats, projects, local tools, plugins and skills used on Windows. Linux keeps native desktop automation outside the built-in Windows/macOS backends; Computer use continues through the CUA Driver plugin.
- Add a verified Linux application-hotfix contract for AppImage installations. The immutable AppImage runtime records its Electron/native/runtime fingerprint, while a compatible hotfix is staged into a versioned user-space application layer, reverified before startup, and rolled back to the previous layer if the successor never reaches a ready window. The mounted AppImage is never rewritten in place. DEB remains package-manager-owned.
- Make update selection platform-aware so a release that has no applicable Windows/Linux delivery artifact is not presented as a broken update. Full releases publish an applicable path for both supported platforms.
- Fix the Linux embedded Browser surface so its native child view follows OneCode UI zoom and dock motion instead of rendering at stale/scaled bounds.
- Preserve fresh OneCode task authorization across the installed ChatGPT skill workflow by routing plans, plugins and sub-agents through the authenticated Core execution envelope. Exact chat/turn ownership guards remain unchanged; unattributed calls are not silently promoted.
- Let an attached image be clicked before Send to inspect a bounded staged preview without exposing its local path to the renderer.
- Bundle the Linux PocketSphinx recognizer/model for the supported Ubuntu 22.04/Python 3.10 runtime instead of requiring a separately installed `python3-pocketsphinx` package. Microphone PCM remains in a child-process pipe and is not written as a raw recording.
- Include the Linux port repairs accepted before this release: native Tailscale operator authorization through polkit, exact connector-name ownership, selected-browser web links, IPv6-unreachable public-probe handling, Happy-Eyeballs resolver access, connected-state grace across transient public-health misses, and exact-current-branch ChatGPT transcript recovery without DOM text guessing.
- Include the 0.4.8 reliability work: durable Continue/Stop ownership, long-response connector keepalives, interrupted-stream failure handling without replay, and bounded diagnostics.

## Updating

**Windows:** use **Settings → General → Check for updates → Install when done**. 0.5.0 is a complete installer and also establishes the compatible base for later Windows application capsules.

**Linux AppImage:** use **Settings → General → Check for updates → Install when done**. 0.5.0 replaces the AppImage as a verified full release. Later compatible application-only releases can use the smaller Linux capsule without replacing the immutable native runtime.

**Linux DEB:** OneCode detects the release and provides the exact DEB; installation remains owned by the system package manager. OneCode does not rewrite root-owned package state during ordinary shutdown.

Profiles, connector settings, projects and saved chats are preserved. The Companion ships with the same 0.5.0 application release. Bridge Protocol remains 19 because this release does not introduce an incompatible app ↔ Companion wire contract.

Installed Linux laptop update acceptance is intentionally left to the manual post-publication test requested by the user; build and package validation use Ubuntu 22.04 WSL and do not modify the laptop.
