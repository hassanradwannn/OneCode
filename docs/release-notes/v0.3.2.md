# OneCode v0.3.2

## Repair candidate — validation in progress

Repairs connector discovery in existing chats and strengthens Windows update/relaunch verification.

- Plugin discovery names this installation's exact configured Core connector, including the device suffix. ChatGPT and Gemini receive their own routing guidance; a ChatGPT connector must not ask for Gemini session credentials.
- Existing chats with a cached direct tool list can use the configured Core connector's already-exposed `exec` tool to discover the live plugin catalog. No new chat or marketplace search is needed.
- The ordinary Install when done path now preserves a Core refresh request for the updated app, even when global automatic plugin refresh is off.
- The Windows updater launches its GUI successor visibly and requires a current, visible, non-minimized loaded window before recording success. It also accepts equivalent three- and four-part Windows version strings.

Update with **Settings → General → Check for updates**, then **Install when done**. Active work is allowed to finish first. Existing plugin permissions and caller bindings remain authoritative; this release does not disable those checks. Legacy packages missing updater metadata still require one manual installation.
