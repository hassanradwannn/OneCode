# OneCode 0.6.21 Beta

Gemini can replace its native Send button while the controlled, tool-free fresh-chat warm-up is becoming ready. The adapter previously retained the earlier button across an asynchronous readiness wait, leaving its exact warm-up text unsent when that control became detached. The first click now commits against the current connected, enabled native control within the original thirty-second preparation budget.

The original editor, draft, route, command claim, trusted-edit and attachment guards remain required throughout preparation. Attachment custody is checked during ordinary ownership reads as well as editor replacement. The click is reserved before native dispatch; an exception, a late receipt or an unanswered accepted click cannot authorize another click or replay the real task.

This candidate includes the 0.6.20 picker responsiveness and stale composer-status fixes and all earlier 0.6.18/0.6.19 reliability repairs. Bridge protocol 19 is unchanged; recorder revision 82 replaces the adapter and observer together.

Native acceptance is still in progress. That transport gate and the installed Gemini warm-up/first-successor-tool checks must pass before Stable publication.
