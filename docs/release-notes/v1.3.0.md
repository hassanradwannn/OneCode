# OneCode 1.3.0

## Highlights

- Choose **srv.us** in Setup to get a stable HTTPS connector URL. OneCode includes the SSH client, creates its own device key, and reconnects automatically after network interruptions.
- Enable **Remote** with srv.us for a separate browser address. An enabled Remote route and an enrolled connector with startup enabled reconnect when OneCode opens. [Relay setup](../../relay/README.md)
- Pair each Remote browser using a one-time link that expires after five minutes. Revoke individual browsers from Settings or turn off Remote to revoke all browser access.
- Choose Tailscale for Funnel or private Remote access, or configure a self-hosted OneCode Relay.
- Advance a ChatGPT Steer when its exact native Send is acknowledged, even if the browser delays the message bubble. Keep tool authorization and the final reply attached to the new turn.
- Give the queued Steer button, delivery status, and cancel action separate space below the message.
