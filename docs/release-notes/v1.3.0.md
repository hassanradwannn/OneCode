# OneCode 1.3.0

## Highlights

- Use OneCode Relay for stable public HTTPS addresses for Remote and provider connectors. Enroll the device once using the address and key from a relay operator. [Relay setup](../../relay/README.md)
- Pair each Remote browser using a one-time link that expires after five minutes. Revoke individual browsers from Settings or turn off Remote to revoke all browser access.
- Keep using Tailscale Funnel for provider connectors or private Tailscale Serve for Remote by selecting that connection method.
- Advance a ChatGPT Steer when its exact native Send is acknowledged, even if the browser delays the message bubble. Keep tool authorization and the final reply attached to the new turn.
- Give the queued Steer button, delivery status, and cancel action separate space below the message.
