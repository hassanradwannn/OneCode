# OneCode 1.0.0

- Paste attachments directly into Gemini’s composer. The Companion stages the files after chat preparation without opening the Files menu.
- Use the first enabled native Send in Claude and Gemini after the requested files are staged and the draft is authorized. The provider can finish processing uploads after Send.
- Preserve the draft if attachment staging fails or the composer changes. Confirm delivery from the provider’s matching user message.

The release includes Windows and Linux x64 installers and compatible application updates.
