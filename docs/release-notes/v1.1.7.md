# OneCode 1.1.7

- ChatGPT Writing cards in Desktop and Remote have a **Copy** button. It copies the card’s original Markdown, including links, lists, and code fences. Saved replies with the original card and copy payload also work.
- Sends with multiple screenshots finish attachment verification when ChatGPT renames files with the same filename. If OneCode cannot confirm an upload, it preserves the draft in the browser.
- Compact & Resume verifies the exact selected ChatGPT model and reasoning effort before sending. If the picker resets in the successor conversation, OneCode can restore it after the resumed turn finishes.

This Stable application update covers Windows and Linux x64. Its compatible complete bases are Windows 0.5.9 and Linux 1.0.7. [Complete installers and packages for fresh installations](https://github.com/hassanradwannn/OneCode/releases/tag/v1.1.6).
