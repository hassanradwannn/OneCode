# OneCode 0.7.3

Fixes a Windows update that could close OneCode without installing or relaunching, leaving Start to open the previous version.

- Restored WSL custody records created before a verified Windows boot can confirm that their Windows leaders exited. The ordinary exact-token WSL scan still must prove descendants absent before custody retires. Same-boot uncertainty and failed OS/WSL reads remain blocking.
- Update preparation checks restored orphan custody before committing to shutdown. A failure shows a recoverable error while OneCode remains open instead of silently exiting without an updater handoff.
- First-time Tailscale setup now explicitly advises allowing up to 15 minutes for public provisioning and verification, with automatic rechecks. This is a practical allowance; Tailscale documents up to 10 minutes for public DNS propagation.
- Includes all Stable 0.7.2 setup, idle-delivery, authorization, streaming, Steer and tool-caption fixes.

Compatible Windows and Linux application capsules retain the verified Stable 0.5.9 bases. Native installed-update evidence is recorded separately from automated tests and packaged runtime smoke.
