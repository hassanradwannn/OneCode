# OneCode 1.1.4

- Fix ChatGPT messages with pasted screenshots getting stuck in the browser composer. ChatGPT can give a pasted PNG a timestamped filename. OneCode now recognizes that name on the image tile created by the current upload and waits for the native Send button to become ready.
- Preserve the existing draft, attachment and Send receipt checks. A previously stalled draft requires its own Send action.

This Stable hotfix provides application updates for Windows x64 and Linux x64. The minimum complete bases are Windows 0.5.9 and Linux 1.0.7. For a fresh installation, use the complete [OneCode 1.1.3 packages](https://github.com/hassanradwannn/OneCode/releases/tag/v1.1.3), then check for updates in OneCode.
