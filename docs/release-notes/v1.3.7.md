# OneCode 1.3.7

## ChatGPT Steer

- Start delivery of an explicit Steer when ChatGPT has removed the original question bubble from the visible page. The Companion verifies the saved question, live turn and chat before sending.
- A newer native question or a different active turn prevents delivery to the earlier turn.

## Install or update

On Windows or Linux x64, open **Settings → General → Check for updates** and select **Install when done** when 1.3.7 is ready. For a fresh installation, start with the complete 1.3.0 package and then check for updates. [OneCode 1.3.0 installers](https://github.com/hassanradwannn/OneCode/releases/tag/v1.3.0)
