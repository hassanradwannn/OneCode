# OneCode 1.1.5

- Use **Fix network** from the Linux connection menu or Tailscale setup when Tailscale stays disconnected. The action requests administrator approval to restart the `tailscaled` service and then checks the connector again.
- Show when Tailscale is running but cannot synchronize with its coordination server, and point to **Fix network** while OneCode continues checking.

This Stable hotfix provides application updates for Windows x64 and Linux x64. The minimum complete bases are Windows 0.5.9 and Linux 1.0.7. For a fresh installation, use the complete [OneCode 1.1.3 packages](https://github.com/hassanradwannn/OneCode/releases/tag/v1.1.3), then check for updates in OneCode.
