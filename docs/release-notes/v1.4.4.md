# OneCode 1.4.4

ChatGPT copy cards for commands, paths and arguments render inline in Desktop and Remote when the saved reply contains the exact card value. Each button copies its own text, preserving quotes, spaces and backslashes when the display wraps.

## Install or update

On Windows or Linux x64, open **Settings → General → Check for updates**. For a fresh installation, start with the complete 1.3.0 package and then check for updates. [OneCode 1.3.0 installers](https://github.com/hassanradwannn/OneCode/releases/tag/v1.3.0)
