# OneCode 0.5.10

Stable reliability hotfix for existing Windows installations. ChatGPT and Gemini retain the provider selected for each new chat independently of Setup's default.

- Keep the bridge response deadline active until its JSON body finishes. An incomplete response can no longer hold the Companion's shared discovery or maintenance flight indefinitely after headers arrive. A timeout supplies no Send receipt and cannot replay an uncertain operation.
- Ignore history failures from an opening or chat selection that has already been cancelled or left. A delayed missing-session response no longer displays a misleading toast over Setup or a different chat. Current missing-session IPC failures record their operation name without private payloads.
- Recover legacy completed terminal results whose pre-truncation cursor exceeds the retained output tail. The stored output hash and ownership still validate; unread output stays retained and commands are never rerun. This repairs the additional Windows legacy record shape that blocked the entire terminal store.

Validation: focused bridge deadlines, provider routing, durable opening, stale-history and terminal recovery regressions; public source verification; packaged Windows runtime smoke. Native acceptance and release artifact verification are recorded separately before publication.

The reported journal access denial cleared after Windows restarted. Its retained file length and modification timestamp did not change. This is evidence of a transient operating-system access condition, not proof of malformed journal content or a specific security product being responsible.
