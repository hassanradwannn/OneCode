# OneCode Beta 0.7.20

Repairs Steer delivery when a native browser snapshot refresh overlaps the authorization response. The existing Send deadline waits only for the same in-flight snapshot, then requires fresh source, conversation, draft and claim proof before clicking.

Withdrawing an unsent app-prepared draft retains the previous acknowledged question only while its exact receipt and document remain unchanged. Human edits, newer questions, foreign views and changed bodies still veto delivery. No uncertain Send is replayed.
