# OneCode 1.4.5

Open reports, benchmark data and launcher source from the reply that delivered them. Desktop and Remote recover local Markdown file links through the approved workspace and can offer multiple files verified by a recorded batch read. Desktop can open a unique new Markdown report alongside its data and scripts.

The bundled ChatGPT skill now shows agents how to link each verified file, including terminal-generated outputs. To replace an older ChatGPT skill, use **Setup → ChatGPT → Save skill ZIP**, then upload it in ChatGPT Skills. [Updated skill source](https://github.com/hassanradwannn/OneCode/blob/v1.4.5/skills/onecode-chatgpt/SKILL.md)

## Install or update

On Windows or Linux x64, open **Settings → General → Check for updates**. For a fresh installation, start with the complete 1.3.0 package and then check for updates. [OneCode 1.3.0 installers](https://github.com/hassanradwannn/OneCode/releases/tag/v1.3.0)
