# OneCode 0.9.8

- Retry a brief Windows lock while atomically saving state. A successful retry keeps the turn running and preserves the original tool result. A sustained storage failure remains recoverable through the saved checkpoint path.
- Bound OpenRouter’s wait for response headers and show the remaining free-request count when OpenRouter supplies it.
- Open links in authored messages and inspect sent images in Desktop and Remote. Record supported browser-sent images with their user messages in ChatGPT, Claude and Gemini.
- Copy native prompts locally when the captured response includes the copy payload. Reserve the interactive-content fallback for actual controls.
- Workers inherit the main chat’s observed effort when their assignment leaves effort unspecified.

The candidate targets Windows and Linux x64 installers and compatible application updates.
