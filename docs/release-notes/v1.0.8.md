# OneCode 1.0.8

- Preserve ChatGPT-generated grids, diagrams, SVG content and standard HTML controls in a safe offline artifact preview instead of flattening their layout into transcript text.
- Capture declarative visual surfaces generically without hardcoded labels, chart schemas or generated values.
- Keep provider scripts, external resources, event handlers and network access outside the preview sandbox. Actions that require ChatGPT's private runtime still open the original conversation.

Windows and Linux x64 compatible application updates for the OneCode 1.0.7 complete base are included. Existing 1.0.7 installers remain the fresh-install base.
