# OneCode Beta 0.7.5

ChatGPT can place a new question inside a section that already held an identified question. Delivery receipts now follow the new native message ID through that reuse, while preserving exact task text, route and receipt checks. Prior message IDs and previously unidentified sections cannot become a new Send receipt. This prevents an accepted Steer from timing out without activating its task authorization.

Gemini's native text-insertion API emits trusted input events even for the adapter's own edits. Fresh recovery initialization now retains its lease through only those synchronous owned mutations. Human edits during permission, readiness and receipt waits still revoke preparation. The one-use initialization receipt, original deadline and actual-task Send guards remain unchanged.

Source regressions and installed native acceptance are recorded separately.
