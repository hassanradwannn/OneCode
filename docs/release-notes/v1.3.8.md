# OneCode 1.3.8

## ChatGPT Steer

- Clicking **Steer** moves the existing queued message ahead of ordinary follow-ups. If a new turn has already started, OneCode verifies the current turn in the same chat. If ChatGPT has finished, the Companion sends the message through the idle composer.
- The same queued message keeps its priority while the browser and OneCode reconcile a turn change. Send authorization and receipt checks still apply.

## Install or update

On Windows or Linux x64, open **Settings → General → Check for updates** and select **Install when done** when 1.3.8 is ready. For a fresh installation, start with the complete 1.3.0 package and then check for updates. [OneCode 1.3.0 installers](https://github.com/hassanradwannn/OneCode/releases/tag/v1.3.0)
