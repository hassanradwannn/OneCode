# OneCode 0.9.10

- Confirm a Claude image upload from its loaded native preview when the upload metadata is unavailable. Send still waits for the matching attachment names, an enabled Send button and any reported upload activity to clear.
- Use Gemini’s current Files menu and read attachments after the recovered chat is bound. The warm-up stays separate from the user’s message and files.
- Import images sent directly in Claude when their native image strip sits beside the message bubble. The strip is matched to the exact turn.

The release includes Windows and Linux x64 installers and compatible application updates.
