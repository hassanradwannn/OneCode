# OneCode 0.8.1

Published [Stable 0.8.1](https://github.com/hassanradwannn/OneCode/releases/tag/v0.8.1) from frozen source `a6186e4f563f56f5ce07155ae5d6d7d84df23743`. See [verification scope](../release-acceptance/v0.8.1.md) for completed checks and pending native acceptance. Publication does not install or restart production applications.

- Preserve the existing question and generation when a native-tab refresh encounters a connection reset or unavailable worker. Reconnect waits for the application's recorded identity instead of opening a duplicate local generation that can invalidate the original task credential. Late failed reads cannot release a successor document's identity gate. No message or uncertain tool action is replayed.
- Capture public native inline `visualize` HTML/SVG source under its exact assistant response and tool-use identity. Display labels, decision branches and palette styles in the shared isolated Desktop/Remote preview. Retain source and local revisions without fabricated generated-file paths or provider revision IDs. Mermaid file rendering remains available separately; HTML/SVG capture is not a Mermaid conversion.
- Size static SVG diagram cards to the diagram's dimensions. Expanded previews center and fit the whole chart, including its legend, within the available screen height.
- Preserve multiline fenced code inside lists and quotations in the shared Gemini/Claude capture path. ChatGPT's rendered fallback also preserves Markdown structure when its native source is unavailable.
- Require the current native question and mounted answer before a completed response footer can close a Gemini or Claude task. A historical greeting cannot revoke a newer task while its local command is still running.
- Show bytes and known totals for capsule, composite and full-image downloads. Unknown totals show indeterminate progress. Verification and preparation remain visible before ready-to-install; cached payloads retain checksum verification. Windows/Linux compatibility, manual DEB upgrades and explicit install/restart ownership remain unchanged.
- Show a Tailscale network wait separately from a failed Funnel permission check. Read-only recovery keeps its existing route custody; it does not reset routes, change policy or replay publication.

Permissions, connector selection and Block/Trust choices remain under their existing owners. There is no greeting turn, automatic task replay or relaxed authorization.
