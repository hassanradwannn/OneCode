# OneCode 0.9.9

- Record images sent directly in provider chats and open imported gallery images at a larger size. Gemini upload retrieval is limited to the visible attachment in the same browser document. The Companion update requests access to `lh3.google.com` and `lh3.googleusercontent.com` for this retrieval.
- Restore ChatGPT image captions and copy prompts directly in OneCode. When the provider capture omits the clipboard payload, Copy prompt uses the visible prompt body.
- Restore teal action nodes and purple decision nodes in imported Claude diagrams.
- See OpenRouter’s reported daily free-request limit in **Usage → Messages and limits**, and refresh it independently of sending a chat message.
- Clarify how to call plugin discovery inside OneCode’s JavaScript tool when a script uses a connector-qualified method name.

The release includes Windows and Linux x64 installers and compatible application updates.
