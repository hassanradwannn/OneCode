# OneCode 0.6.23 Beta

Explicit Steer now offers the exact message to the provider's native composer instead of waiting for a separate Main Stop operation. ChatGPT can send while running. Gemini uses its native Send when available; layouts that retain Stop use one native Stop under the same draft and input claim before Send becomes ready. Local processes are preserved. Source question, turn, draft, connector and accepted-message receipts remain required, and an uncertain Send is not replayed.

Preparing a new Gemini input retains the source task's grant until the new input is accepted. Both providers preserve the internal receipts of already admitted tool calls through successive steering messages, while superseded raw credentials, canceled inputs, foreign connectors and blocked chats remain refused. The Gemini ledger writes version four and reads its older supported formats; an older application rollback fails closed on the new format. Native runtime compatibility is unchanged.

Mermaid diagram artifacts now render offline instead of falling back to plain source text. The isolated preview retains the original source and exports, shows parse failures visibly, and keeps its existing network and host-access restrictions. Plugin discovery now returns compact, bounded catalog pages and retrieves exact schemas separately, leaving room for inspection results without increasing code-mode budgets.

This candidate also includes the model-picker close transition repair from 0.6.22 and the earlier queue, auto-allow, interruption, handoff and stale-status repairs. Bridge protocol 19 is unchanged; recorder revision 84 replaces the native adapters and observer together.

Source regression tests and isolated Electron rendering checks are separate from installed native acceptance. The Windows and Ubuntu live-tool, steering, interruption and first-successor-tool cases remain required before Stable publication.
