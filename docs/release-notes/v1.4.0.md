# OneCode 1.4.0

ChatGPT workers can use their own OneCode tools and report to the prime agent when the browser records the worker’s first message but misses its send receipt. OneCode verifies that the recorded message belongs to that worker’s launch before restoring access.

## Install or update

On Windows or Linux x64, open **Settings → General → Check for updates** and select **Install when done** when 1.4.0 is ready. For a fresh installation, start with the complete 1.3.0 package and then check for updates. [OneCode 1.3.0 installers](https://github.com/hassanradwannn/OneCode/releases/tag/v1.3.0)
