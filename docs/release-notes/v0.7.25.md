# OneCode Beta 0.7.25

This experimental Beta includes long-session reliability changes for evaluation:

- History recovery clears a rate-limit wait only for the matching current conversation and retry episode.
- Steer reconciliation preserves unresolved public output without assigning it to a preceding turn. A changed target preserves the input for a safe later send.
- Exact late delivery acknowledgements update sent status while preserving user cancellation and preventing cancelled automation from restarting.
- Exact terminal evidence can retire stale working state; pending Compact & Resume preparation wakes when the provider becomes writable and requires a terminal response witness.
- ChatGPT task grants remain stored through reversible Block and ambiguous attachment states while those states continue to refuse execution. The original receipt and turn are revalidated after recovery.
- Existing journal and browser recovery protections retain their exact task and document ownership.

This is a candidate for Windows native acceptance, not an accepted Stable release. The cause of the reported intermittent authorization failure has not been conclusively established; the repairs above address reproduced grant-loss paths. The full content-script test had not produced a final verdict at candidate preparation. Validate long-running task authorization, Steer, history, restart, journal recovery, handoff and browser reconnection with the real OneCode connector and provider before promotion. Do not replay uncertain actions.
