# OneCode 0.6.7 Beta candidate

Stable and Beta Companions in one browser profile could repeatedly remove and reinsert each other's composer controls, starving native page timers. A bounded two-world DOM regression reproduces this behavior. Composer controls and progress panels now retain an extension-installation cleanup namespace and avoid legacy blanket cleanup markers. Shared styling and native-content exclusion classes remain compatible. These presentation markers grant no provider or task authority.

Recorder revision 72 replaces older content closures; bridge protocol 19 is unchanged. This candidate includes the 0.6.4–0.6.6 recovery, Stop/restart, bounded startup/keyring waits, native OS routing, recorded file-link and centered-preview fixes.

Native coexistence, Windows/Linux, ChatGPT/Gemini, Desktop/Remote and installed updater acceptance remain pending. The reported overnight Windows crash still has no proved cause. Stable promotion remains gated on the requested acceptance. Full releases and compatible application capsules are built on GitHub from the frozen candidate source.
