# OneCode Beta 0.5.7

Unpublished validation candidate, retaining the terminal, worker, Stop, folder-approval, journal-preservation and Remote repairs from the 0.5.6 draft.

- **Share a folder keeps the current chat.** The composer now opens folder approval directly, preserving the selected chat and its draft. Explicit standalone written folder grants use that same approval owner and become available to existing tools immediately.
- **Shutdown includes live commands with closed output streams.** Exact Windows process-tree stops remain bounded in concurrency; the outer shutdown deadline now accommodates the full terminal capacity before permitting an update handoff.
- **History cursors stay consistent.** The local control API pages by its published immutable origin positions, preventing revised answers from repeating across pages. Desktop and Remote retain their display-position navigation.
- **Native skill openings remain compact.** Current virtual and native folder paths retain their live-grant guidance within the existing small-prompt budget.
- **Approval mismatches are visible in every Companion language.** The warning keeps automatic approval paused for a different connector and explains where to check its configuration.

This draft is not acceptance for stable publication. Persistent operating-system journal access denial, the complete validation suite, and installed internal-update acceptance remain release gates. No history reset or security-protection change is included.
