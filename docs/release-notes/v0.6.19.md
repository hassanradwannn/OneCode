# OneCode 0.6.19 Beta

Gemini approval cards can display tool names such as `write stdin`. The adapter now reads the complete native tool name and checks that exact configured connector's enabled tools. A multiword tool cannot borrow the permission of its first word.

Steer no longer records a native Stop as attempted when an approval prevents the click. The same command can try its real Stop after that approval settles. A guarded recovery refresh refuses pending native approvals, unsettled approval receipts, blocking errors, drafts, attachments and exact running local requests. The browser rechecks that proof and its unchanged connection immediately before navigation. The fallback refreshes the original tab instead of closing it and depending on automatic tab recovery to reopen it; the original queued input still requires native Stop confirmation before Send.

Compact & Resume command custody now restores the canonical continuation token format after an app restart. Bounded authorization diagnostics identify which exact receipt checkpoint is still pending without logging task text or credentials.

This candidate includes the 0.6.18 transport-lifetime, local progress, observer-restoration, connector-chip, failed-notice cleanup and updater-network repairs. Bridge protocol 19 is unchanged. Recorder revision 80 replaces the observer and adapter together.

Native Windows and Ubuntu acceptance is in progress. The live first-tool authorization failure after Compact & Resume is not yet classified as repaired. Stable publication remains gated on the specific interruption, approval, queue, Steer and resumed-tool cases.
