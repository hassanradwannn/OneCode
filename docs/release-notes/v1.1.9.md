# OneCode 1.1.9

- Explicit Steer in ChatGPT, Gemini and Claude now takes priority over a pending browser recovery check. Running workers keep their assignments and continue reporting to the same chat.
- If the browser already received permission to refresh that exact chat, OneCode waits for the refresh to settle before offering the message to the correct page. Regular queued messages still wait for their turn.

This Stable application update covers Windows and Linux x64. Its compatible complete bases are Windows 0.5.9 and Linux 1.0.7. [Complete packages for fresh installations](https://github.com/hassanradwannn/OneCode/releases/tag/v1.1.6).
