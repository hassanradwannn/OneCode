# OneCode 1.3.1

## ChatGPT tool authorization

- OneCode puts the current task’s authorization instructions up front and repeats the recovery steps when ChatGPT omits the authorization from a tool call.
- `CALLER_IDENTITY_REQUIRED` tells ChatGPT when no tool ran and how to retry the rejected call with the same message’s authorization. The connector still verifies the exact task before granting access.

## Install or update

On Windows or Linux x64, open **Settings → General → Check for updates** and select **Install when done** when the download is ready. This release is an application update. For a fresh installation, use the complete 1.3.0 installer or Linux package, then check for updates. [OneCode 1.3.0 installers](https://github.com/hassanradwannn/OneCode/releases/tag/v1.3.0)
