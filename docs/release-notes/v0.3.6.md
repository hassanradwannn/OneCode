# OneCode 0.3.6

Gemini Compact & Resume now uses the same delivery contract as ChatGPT: the model returns a complete Markdown brief, OneCode saves the exact completed response locally, and the app opens a new chat on the same provider with that brief. Current handoff prompts make no tool calls and therefore need no native tool approval to save the handoff.

Capture still requires the exact handoff question, one completed generation, its final answer and settled local tools. A streaming or interrupted brief cannot open a successor. Gemini's source browser, document and account custody checks remain in force. Already-issued requests that explicitly use the older scoped save tool remain supported.

Trusted manual Allow/Deny clicks now receive the same exact decision-exchange tracking as Companion clicks. Gemini's generated approval reply no longer appears as a new authored task that cancels compaction. Ordinary typed Allow messages, foreign cards, expired receipts and untrusted clicks remain ordinary messages.

Auto-approval includes the actual published title of each enabled tool on its matching connector, fixing native cards whose displayed title was absent from the previous name-only aliases. It does not enable disabled tools or approve another connector.

Fresh Gemini preparation also preserves its existing command through a controlled editor replacement during the empty stage before warm-up. The replacement must be empty, Send disabled, attachments unchanged and the same route/claim retained. Human drafts and unconfirmed native state still stop Send.

The displayed version is **0.3.6**. Windows, Companion and updater version **0.3.600** upgrades from **0.3.500**. Windows x64 updates preserve profiles and recorded chats. Development tests remain local and ignored by Git as requested.

ChatGPT Setup now exports the optional onecode-chatgpt skill as Markdown or ZIP. After installing and enabling it in ChatGPT, users can select the matching OneCode option to shorten repeated guidance. Each message still carries fresh authorization for its exact task; the option grants no additional access. Accounts without native Skills retain the existing full instructions.

Late progress messages now retain their response placement when the native page exposes them after the final answer, including responses with multiple requests or no native request correlation. Conflicting identity is refused and historical backfill does not count as active work.

Computer use guidance prefers the enabled live plugin bridge and its current schemas. The skill pack version alone cannot establish that the daemon is outdated. The existing browser/desktop setting and plugin permission behavior are unchanged.

Validation includes 1,280 provider regression tests, focused history checks, screenshot and authorization tests, TypeScript, production verification and packaged Windows runtime smoke. The installed candidate preserved 98 recorded chats. The user confirmed the requested manual tests working and approved publication. See [release acceptance](../release-acceptance/v0.3.6.md).

Code mode now forwards native MCP screenshot blocks as validated images when the agent explicitly prints the result. The text output contains image placeholders and ordinary metadata, preventing screenshot base64 from exhausting the text budget after CUA actions. Unprinted results remain private; ordinary strings, image limits and image validation retain their behavior. Screenshot and authorization regressions: 22 passed.

Download **OneCode-Setup-x64.exe** for Windows x64, or use **Settings → General → Check for updates** in OneCode. The release includes the matching Companion ZIP, both optional provider skills, verified update metadata and SHA-256 checksums. The stable updater uses package version 0.3.600 to upgrade from 0.3.500 and earlier supported installations.
