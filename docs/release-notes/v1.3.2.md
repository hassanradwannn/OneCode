# OneCode 1.3.2

## Compact & Resume

- Wait for ChatGPT’s new composer to confirm the saved model and reasoning effort after the native picker closes. This also applies to **Open a new chat with this summary**.
- Use the native picker toggle when it owns the open menu, and read the current composer even if the closed menu remains mounted. OneCode checks the same model and effort again before sending the handoff.

## Install or update

On Windows or Linux x64, open **Settings → General → Check for updates** and select **Install when done** when the download is ready. For a fresh installation, use the complete 1.3.0 installer or Linux package, then check for updates. [OneCode 1.3.0 installers](https://github.com/hassanradwannn/OneCode/releases/tag/v1.3.0)
