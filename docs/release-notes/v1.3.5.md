# OneCode 1.3.5

## ChatGPT Steer and Compact & Resume

- Keep commentary that was already visible above the Steer when ChatGPT later assigns that commentary to the following turn. The same order appears when you reopen the chat.
- Recognize the saved ChatGPT model when the new composer uses a native alias for the same model. Compact & Resume and **Open a new chat with this summary** verify the saved model and reasoning effort before sending the handoff.

## Install or update

On Windows or Linux x64, open **Settings → General → Check for updates** and select **Install when done** when the download is ready. For a fresh installation, start with the complete 1.3.0 package and then check for updates. [OneCode 1.3.0 installers](https://github.com/hassanradwannn/OneCode/releases/tag/v1.3.0)
