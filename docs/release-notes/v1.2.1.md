# OneCode 1.2.1

- Linux verifies the installed executable and prepares compatible application layers before quitting. A preparation failure leaves the current application open.
- If the relaunch observer cannot be started, OneCode restores the previous application selection. The observer checks the executable after shutdown and allows a slow Linux startup more time to confirm a visible window.

This Stable application update covers Windows and Linux x64. Its compatible complete bases are Windows 0.5.9 and Linux 1.0.7. [Complete packages for fresh installations](https://github.com/hassanradwannn/OneCode/releases/tag/v1.1.6).
