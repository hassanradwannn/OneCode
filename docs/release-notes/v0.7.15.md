# OneCode Beta 0.7.15

Adds bounded, deduplicated diagnostic flags for existing Compact and Resume source-proof checks: acknowledged receipt, current native section, stable native order, exact submitted body and immutable completed reply proof. Diagnostics contain only fixed booleans and counts, with no message contents, identifiers or credentials.

The source guards, delivery rules and authority checks are unchanged from Beta 0.7.14. The recorder revision loads the diagnostic closure as a matched pair. Native acceptance remains separate from source and package verification.
