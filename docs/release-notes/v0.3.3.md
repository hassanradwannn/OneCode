# OneCode v0.3.3

Gemini workers start and resume more reliably, and model choices follow the account currently selected in the browser.

- Retire stale Gemini recovery waiters before an unclaimed handoff, and preserve the recorder's adapter during overlapping extension injections. Existing workers retain their conversation and can wake without closing other Gemini tabs.
- Gemini workers recognize the provider's current model. The picker shows one **Automatic** option, excludes locked choices such as Argon, and refreshes from the selected account. ChatGPT refresh also prefers the selected native page and retains its native availability checks.
- Preserve worker delivery receipts and task authorization through native acknowledgements, policy refresh and resumed tool calls. Local caller capabilities remain scoped to the exact task and provider.
- Include the pending connector-discovery and Windows updater repairs: existing chats discover live installed plugins through their configured Core connector, and installation verifies a loaded visible successor window.

Windows x64 users can update through **Settings → General → Check for updates**, then **Install when done**. The release includes architecture-specific updater metadata, the installer blockmap, SHA-256 checksums and the matching Companion. Existing profiles and chat history are preserved. Very old installations without updater metadata require one manual installation.

Validation covered the browser adapters, worker delivery, account/model discovery, production composer, TypeScript, build and packaged Windows runtime. Installed Gemini acceptance woke the same worker and verified its existing two-byte files without writing them. The inherited full test suite still contains obsolete fixtures; it is not claimed to be entirely green. This release supplies Windows x64 artifacts.
