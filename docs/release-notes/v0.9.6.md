# OneCode 0.9.6

- Workbench keeps browser storage and tabs separate for each chat. Open **New browser tab** from the dock menu and switch tabs directly. Known local preview ports are reserved across loopback aliases.
- Import supported standalone web builds directly from the output directory. The offline artifact uses the actual build files, including bundled JavaScript.
- Desktop and Remote show reasoning levels reported by OpenRouter for the selected model. Models without a reported selector use the provider default.
- **Install when done** waits for API turns, provider retries and manual compaction. **Update now** keeps the immediate restart path.
- Set **Sub-agent workers** to **0** for automatic capacity up to eight per chat. Saved numeric limits remain in effect.

The release includes Windows x64 and Linux x64 installers and compatible application updates.
