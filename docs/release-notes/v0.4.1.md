# OneCode 0.4.1

Fixes a Tailscale connector stuck at **Connecting / Public DNS check failed** on a hotspot or another network where Google DNS over HTTPS cannot be reached.

OneCode's Cloudflare DNS request previously used a combined Accept header that Cloudflare rejected with HTTP 400. Google DNS could hide that failure on other networks. The request now uses Cloudflare's required `application/dns-json` media type, while bounded response validation accepts both resolvers' JSON formats. Either resolver can independently complete public DNS, verified HTTPS, exact connector metadata and MCP initialization.

This shared fix covers ChatGPT and Gemini connectors on all updated installations. Saved URLs, private Remote routes, account state, permissions and chats are preserved. No system DNS change, route reset or sign-in reset is required. All 0.4.0 features remain included.

Update through **Settings → General → Check for updates → Install when done**, or run the Windows x64 installer manually. The matching Companion updates when chats are idle.

See the [acceptance record](../release-acceptance/v0.4.1.md) for the reproduced failure, live laptop checks and remaining limits. Network blocks, captive portals and account consent can still prevent access.
