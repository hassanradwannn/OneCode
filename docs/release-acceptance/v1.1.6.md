# OneCode 1.1.6 release report

[OneCode 1.1.6](https://github.com/hassanradwannn/OneCode/releases/tag/v1.1.6) became the latest Stable release on November 19, 2026 at 6:15 p.m. Cairo time. The complete packages and both application capsules were built from `897f5cb7b43afe4d6d70428f13ad051460ccbef4`.

## What changed

- Requests for copyable Markdown now tell the agent to save a regular `.md` file and link it in the response. The document opens in the sidebar with a **Copy Markdown** control for the original source. The same control is available in the Files preview for a complete Markdown file.
- In replies, ordinary Markdown links label web destinations. A link such as `[Guide](onecode-file:/project/docs/guide.md)` opens an approved text file through the recorded assistant message. Paths resolve through the live workspace permissions. Native reply markup retains its interactive content if a missing document link needs to be restored.
- A completed reply with recorded edits shows a file list and line totals. **View changes** opens the turn's recorded snapshots in the sidebar. Click a file to inspect its saved diff and use the edit selector when several snapshots exist for that file. Totals describe recorded operations, and the review reads the saved before and after text for each edit.
