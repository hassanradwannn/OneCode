# OneCode 0.5.5 candidate acceptance

Date: 2026-10-23. Canonical branch: `release`.

**Status: stable unpublished; native Linux capsule repair and acceptance in progress.** Production sessions are outside the isolated Beta profiles.

The 0.5.1, 0.5.2 and 0.5.4 acceptance records retain the earlier reliability tests, Windows updater passes, Linux defects found by actual installed tests, and candidate withdrawals. The published complete Beta 0.5.3 base passed installed full-update acceptance on Windows and Linux. Windows used differential reconstruction against its genuine cached prior installer. Linux confirmed the exact published AppImage and one visible successor through the native nonced receipt. Browser and profile settings were retained.

Beta 0.5.4 exposed a separate native-package ownership defect: application-sidecar archives intentionally do not contain the immutable base's unpacked native packages. An isolated real Electron main-process probe reproduced failed sharp, tree-sitter, tree-sitter-bash and node-pty imports from the sidecar, then loaded the same packages from the mounted complete base. The application handoff reported failure and performed no replay. The Beta feed was withdrawn and stable 0.5.4 was withheld.
