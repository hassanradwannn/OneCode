# OneCode 1.1.4 acceptance

[OneCode 1.1.4](https://github.com/hassanradwannn/OneCode/releases/tag/v1.1.4) was published as the latest Stable release on November 19, 2026 at 12:17 a.m. Cairo time. The frozen source for both x64 capsules is `b93914fffd5e70fe392f4437f6e98e391738f732`. Complete packages for fresh installations remain available from [OneCode 1.1.3](https://github.com/hassanradwannn/OneCode/releases/tag/v1.1.3).

## Failure and regression checks

On Ubuntu with Brave and Companion 1.1.3, the outbox recorded browser pickup but no Send authorization. ChatGPT showed the attached clipboard PNG under a timestamped filename and enabled its Send button. The attachment check was still waiting for the original `image.png` name. The patch recognizes the provider's timestamped name for a fresh image tile in the current upload window and retains the existing draft and Send receipt checks.

The new regression reproduced the stall on the old adapter and passed after the fix with exactly one authorization and one Send. It also checks refusal for old timestamps, ambiguous attachments, generic file tiles and other input names. The focused local run passed 654 tests in seven files, and `npm run verify` passed. The earlier broader sweep reported bridge and desktop-maintenance failures. The 31 desktop-maintenance failures reproduced against the unchanged baseline background script.
