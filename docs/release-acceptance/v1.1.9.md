# OneCode 1.1.9 release report

[OneCode 1.1.9](https://github.com/hassanradwannn/OneCode/releases/tag/v1.1.9) became the latest Stable release on November 20, 2026 at 7:03 p.m. Cairo time. Both x64 updates were built from `9799dda7393ca1638047cea30926e74b6299da91`.

## Steer while workers are running

The reported Ubuntu Steer was picked up by the browser after 92 seconds and acknowledged by ChatGPT after 96 seconds. During that wait OneCode repeatedly offered a recovery probe for the same chat. The Companion withheld the user message until those probes cleared.

An exact user Steer now takes priority over speculative recovery in ChatGPT, Gemini and Claude. An already authorized browser action retains its original receipt, and the browser can still restore a missing or suspended document. Worker assignments stay active. OpenRouter applies Steer at the next safe model or tool boundary while workers continue in their own sessions.

## Verification

Twelve focused tests passed. They covered an active worker and an outstanding recovery probe in each browser provider, stale recovery claims, ordinary queued input, Claude's native Send receipt, and an OpenRouter prime applying Steer while its worker continued streaming. All four new Companion regressions failed against the preceding Companion and passed on the candidate. The broader Companion suite had the same 31 other failures on both builds. Other broad tests still include browser-only fixtures that assume OpenRouter has a native browser adapter.

[GitHub run 44778455121](https://github.com/hassanradwannn/OneCode/actions/runs/44778455121) passed public source verification, Windows and Linux packaged runtime smoke, and checksum finalization. Both downloaded archives and every manifest-listed file matched the checksums. The Companion stamp `027ac0174d10` matches the frozen source on both platforms.
