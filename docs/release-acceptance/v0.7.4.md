# OneCode 0.7.4 verification scope

The application tag freezes the release source. Publication and platform build receipts are recorded in the release notes after the GitHub jobs finish.

## Native observations

Read-only inspection used the installed Windows CUA Driver CLI and a signed-in Brave browser. No message was submitted to either provider, and no provider-issued local tool call was requested.

- ChatGPT's evaluated merged picker exposes a separate `defaultOption.selected`, named model options, evaluated power selections and a selected power. The native trigger controls its menu through `aria-controls`; model rows use `menuitemradio` and reasoning uses an owned Power control. The old and merged schemas are covered separately by regression fixtures.
- Gemini's native model menu supplies exact `data-mode-id` values. Its Thinking level row controls a separate submenu containing Low, Medium and High on the observed model. A selected class plus the native Selected checkmark proves selection; hover state does not.
- Clicking an expanded Gemini Thinking level row closed both menus. Discovery and cleanup account for detached controls and recheck the exact model and level.

## Automated checks

Focused regression suites cover the native picker schemas, exact discovery restoration, Chat/Work affinity through queued input and continuation, default Chat opening, model and effort verification after Gemini warm-up, bounded optional skill lookup, concurrent read-only reuse probes and coalesced keep-awake bookkeeping. They retain exact document, draft, account, claim and pre-Send authorization guards.

A broader Steer fixture reproduced a pre-existing race on the previous release's source. The repair captures the already accepted native source when DOM rows are absent; its regression proves that the next Send waits for the pending frame commit. Seventeen neighboring success and ownership-refusal cases passed. Remote history's older test mock was also repaired to return the bootstrap value required by the connection API; runtime connection behavior was unchanged.

The local suite remains intentionally unpublished. Public verification checks privacy, notices, TypeScript and production bundles. GitHub builds Windows and Linux artifacts from the frozen source and runs each platform's packaged runtime smoke and compatible-base checks before publication.

## Limits of this evidence

Menu observation and fixture checks do not prove an installed update or a complete native task lifecycle. Installed 0.7.4 updates, native Linux browser acceptance and exhaustive Desktop/Remote task acceptance were not exercised here. The maintainer requested production testing and manual installation; no production installation or restart was performed for this release.
