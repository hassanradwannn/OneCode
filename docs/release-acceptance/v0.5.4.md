Date: 2026-10-23. Canonical branch: `release`.

The 0.5.1 and 0.5.2 acceptance records retain earlier reliability checks and the defects discovered during native testing. The probe opened no windows and used no signed-in browser profile. Sixty focused checks and TypeScript passed. `verify:ci` passed at the 0.5.3 full-base checkpoint `831b651`.

## Final candidate observations

The corrected cloud workflows passed on Windows and Ubuntu 22.04 for the 0.5.3 Beta full base and the 0.5.4 stable candidate. Strict checksum inventories covered 13 Beta payloads and 17 stable payloads, without the excluded native-source archive. The clean builds also exposed and repaired invalid historical gen-mapping lockfile metadata without changing its authentic dependency bytes.

The installed Windows app reconstructed the published 0.5.3 installer through the differential path and reopened its verified visible successor. Linux installed that exact published 0.5.3 AppImage and confirmed its successor through the nonced native ready-window receipt.

The subsequent Linux compatible 0.5.4 capsule passed archive validation but did not reach a window. An isolated real Electron main-process probe reproduced native-package resolution failures from the sidecar: those packages are deliberately retained in the immutable base's unpacked resource tree. The same packages loaded from the exact mounted base. The handoff correctly recorded failure and did not retry or report readiness. This remains a failed native acceptance check; the stable candidate was not published.
