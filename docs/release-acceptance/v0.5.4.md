Date: 2026-10-23. Canonical branch: `release`.

**Status: not published as stable; final installed acceptance in progress.** Tests use separate Beta installations and profiles.

The 0.5.1 and 0.5.2 acceptance records retain earlier reliability checks and the defects discovered during native testing. The probe opened no windows and used no signed-in browser profile. Sixty focused checks and TypeScript passed. `verify:ci` passed at the 0.5.3 full-base checkpoint `831b651`.
