# OneCode 1.2.0 release report

[OneCode 1.2.0](https://github.com/hassanradwannn/OneCode/releases/tag/v1.2.0) became the latest Stable release on November 20, 2026 at 10:44 p.m. Cairo time. Both x64 updates were built from `2ec9d09d58f382bd4c702ab88317bf972b82876c`.

## Compact & Resume

Ubuntu recorded the source handoff and opened a replacement tab. The continuation requested GPT-6 High. The browser then reported `selection-changed-after-close` before sending the saved handoff. The original chat and handoff remained available.

The ChatGPT adapter now closes the expanded picker through its own native toggle after selecting the requested effort and checks the closed composer for the exact pair. Resume checks that pair again before authorizing the destination Send. The regression fixture reproduces Escape restoring Instant and verifies that the toggle keeps High. It also verifies that a genuinely reset selection still refuses to send.

## Steer and worker authorization

One Ubuntu Steer took 160 seconds to reach confirmed delivery while automatic compaction was pending. Another later tool request was refused for an invalid credential format. The logs did not show worker authorization being revoked.

A proven user Steer now takes priority before either compaction Send. Any saved brief remains available for reuse, and a Send that already crossed its boundary retains its receipt. The Companion can offer Steer to an open prime before browser-wide maintenance. Routine Steer setup gives the prime its own grant without scanning other chats for expired grants. Harmless whitespace around an exact credential is accepted. Malformed, mismatched, stale and foreign credentials still require their exact authority checks.

## Verification

Twenty-five focused regressions passed across ChatGPT, Gemini, Claude and OpenRouter. An integration test held a worker tool call open while the prime received Steer and ran a tool with its new credential. The worker then finished its first call and made another with its own credential. The broader Companion suite retained the same 31 failures as the preceding candidate, and the new priority regression passed only on the final candidate.

[GitHub run 44813308828](https://github.com/hassanradwannn/OneCode/actions/runs/44813308828) passed source verification, packaged runtime smoke on both platforms and checksum finalization. The downloaded archives, their manifest-listed files and the uploaded digests matched. Both packaged Companions match the frozen source with stamp `56ecdef08c5f`.
