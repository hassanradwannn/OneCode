# OneCode 0.9.11 Beta — validation record

The reported first attempt ended with `COMPACTION_SUMMARY_FAILED`; a later attempt compacted successfully and resumed the task. The old diagnostics did not distinguish an empty, truncated, tool-bearing or oversized summary, so the exact first-response category is unproved. The later `node test-api.js` exit 1 is a separate task test failure, not evidence that compaction remained stuck.

Two source defects were confirmed: pre-Send recovery captions were stored in the delivery-error field, and API compaction emitted no structured lifecycle for the existing Compact & Resume card. This candidate separates informational outbox status, records one durable app-owned workflow row per compaction and updates its folded metadata through archive, summary, merge, retry, save and resume. The saved checkpoint retains the workflow identifier and public handoff. Resume is recorded only after actual task-request acceptance. A presentation identifier is not a native continuation ticket, a new task receipt or an authorization grant.

Summary validation permits three attempts per part. Empty or length-limited responses can expand the completion allocation to the available selected-model ceiling; retries request shorter factual text. Empty completion envelopes, overlong public text and proposed tools have separate recovery paths. No summary tool executes. Valid parts are cached under a versioned policy, with compatible short legacy summaries reusable. Original archives, complete tool-pair retention, exact unread-output receipt requirements, cancellation and current-owner checks remain intact. Diagnostics contain typed categories and numeric sizes/budgets, never raw conversation or provider error prose.

Validation uses isolated fixtures and profiles. No production chat, process, credential, installation or stored failure has been changed by maintenance. Final local and cloud/publication receipts are recorded below. Installed and real-provider acceptance remain pending, and Stable stays unfrozen and unpublished.
