# OneCode 1.1.8 release report

[OneCode 1.1.8](https://github.com/hassanradwannn/OneCode/releases/tag/v1.1.8) became the latest Stable release on November 20, 2026 at 6:27 p.m. Cairo time. Both x64 updates were built from `529b8115c82736166a6e7b09ef1faefbe4ec56c7`. [OneCode 1.1.6](https://github.com/hassanradwannn/OneCode/releases/tag/v1.1.6) provides complete packages for fresh installations.

The reported Compact & Resume attempt had an accepted source question and about 51,000 characters of recorded assistant text. The recording still marked the response as streaming and held no completed turn, saved handoff or replacement conversation. The ticket was later cancelled. The new capture checks the exact current native branch for a completed response and preserves a healthy ChatGPT stream during recovery. Progress text alone cannot open a replacement conversation.

## Verification

The local checks passed 1,163 focused tests and `npm run verify`. The handoff tests cover delayed terminal flags, an exact completed answer with a locally open turn, healthy and broken streams, and rejection of partial or different-branch replies. The Desktop checks cover preserving the submitted delivery choice, same-row Steer with attachments, a stale target, and queued thumbnails and previews. An offscreen Electron check exercised the queue at a narrow window size.

[GitHub run 44772794845](https://github.com/hassanradwannn/OneCode/actions/runs/44772794845) passed public verification, packaged runtime smoke on both platforms and checksum finalization.
