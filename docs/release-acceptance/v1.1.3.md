## Failure and repair

The loaded Companion was confirmed as the published 1.1.2 build. Gemini can append the thinking level to the native model caption, while its primary model span retains the actual model name. Treating the entire caption as the model can reject a valid checked choice. The former reader also constrained secondary captions to one model-row role and relied on trigger toggling to close the thinking submenu.

The repair reads the exact primary native span when available. A combined legacy caption requires the same checked model and an independently observed thinking selection; it is not handled by guessing or stripping familiar words. Both visible model captions are retained across row roles. Thinking rows remain bound to their trigger's exact controlled menu/radio group, with unique checked-state and known-effort validation. Escape closes owned submenus; a legacy fallback rechecks the exact submenu before acting. Original caller, route, editor, draft, attachment and native model checks remain in force.
