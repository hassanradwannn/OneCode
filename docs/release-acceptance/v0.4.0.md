## Scope and limits

The native acceptance platform is Windows x64. Narrow desktop-browser layout checks do not constitute a physical phone or other-platform acceptance run.

Local video presentations support MP4/WebM files up to 128 MiB within the existing session-storage quotas. Gemini native image export is a rendered PNG; this does not establish original-file export, native video-generation export or native Canvas parity. Historical unavailable image placeholders are not proof that their original bytes were recovered.

The host must remain awake with OneCode running and the provider signed in for recurring checks. A provider-native Monitoring card alone does not register a OneCode schedule. A delivered check message does not prove the model inspected a job or that its output succeeded.

Tailscale setup retains native installer, account and administrator consent. A clean-machine Tailscale installation/sign-in and the reported laptop's physical hotspot cold boot were not reproduced on this already-configured host. Read-only startup, offline/recovery, permission, route-custody and timeout cases have automated coverage. Network/carrier restrictions and captive portals can still prevent reachability. Remote must be enabled on the host, with Tailscale connected on both devices; browser-level failures before the page loads require restored reachability and reloading the saved bookmark.
