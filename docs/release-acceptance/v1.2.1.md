# OneCode 1.2.1 release report

[OneCode 1.2.1](https://github.com/hassanradwannn/OneCode/releases/tag/v1.2.1) became the latest Stable release on November 21, 2026 at 2:54 a.m. Cairo time. Both x64 updates were built from `6a31e25c8e78de600b79098740f4eed7b6b2c82a`.

## Ubuntu failure and recovery

Two earlier attempts to install 1.2.0 exceeded the 30-second shutdown handoff deadline. A third attempt selected a complete 1.2.0 application layer but reported that it could not verify the successor before launch. The installed AppImage matched its prior SHA-256, and every selected 1.2.0 layer file matched the published package. Opening the normal desktop launcher recovered 1.2.0 and reconnected its Brave Companion.

For compatible Linux updates, 1.2.1 prepares the layer and validates the executable before quitting. The shutdown handoff rechecks the prepared executable's identity, and the detached helper independently verifies the file after the predecessor exits. A relaunch preparation error during activation restores the previous layer selection. The detached observer gives a slow successor more time to prove that its window is ready.

The installed Ubuntu app found 1.2.1 through **Check for updates** and verified the downloaded capsule. **Install when done** closed 1.2.0, and the detached updater started exactly one 1.2.1 successor. The native window receipt confirmed the successor at 3:10 a.m. Cairo time. The original AppImage, its inode and checksum, and the profile were retained. The successor loaded the 112-session catalog and Brave reconnected with Companion 1.2.1. This live upgrade used 1.2.0 as the predecessor.

## Verification

All 162 focused updater, Linux layer, handoff, bootstrap, and shutdown tests passed. Three separate renderer readiness tests reproduced the same failures on the 1.2.0 source. An isolated Ubuntu probe used the exact packaged helper with real Linux processes and a fixture receipt to confirm that it waits for the predecessor and launches once.

[GitHub run 44846308345](https://github.com/hassanradwannn/OneCode/actions/runs/44846308345) passed source verification, packaged runtime smoke on both platforms, and checksum finalization. The downloaded archives, manifest-listed files and uploaded digests matched. Both packaged Companions carry stamp `4c79a9f1622f`.
