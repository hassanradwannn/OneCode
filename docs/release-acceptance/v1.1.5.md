# OneCode 1.1.5 acceptance

[OneCode 1.1.5](https://github.com/hassanradwannn/OneCode/releases/tag/v1.1.5) was published as the latest Stable release on November 19, 2026 at 4:50 a.m. Cairo time. The frozen source for both x64 capsules is `9092cd14601cbed6d5511f798f9c1f99c71947c3`. Complete packages for fresh installations remain available from [OneCode 1.1.3](https://github.com/hassanradwannn/OneCode/releases/tag/v1.1.3).

## Failure and recovery

On Ubuntu, OneCode and its Brave Companion connected locally after an app restart. Tailscale itself remained out of sync with its coordination server even though a fresh control handshake succeeded. Restarting the Ubuntu Tailscale service restored native network health. OneCode then reported **Connected**, and a command completed through the Ubuntu connector.

The new Linux **Fix network** action requests system administrator approval to restart only `tailscaled.service`. The connection owner checks for running tools and revalidates native route custody and the public connector after the restart. Tests cover the exact Linux command, approval launch failures, repeated clicks, startup during an out-of-sync wait, and both desktop entry points.
